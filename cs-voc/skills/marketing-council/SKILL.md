# 마케팅 카운슬 (Marketing Council)

마케팅 시안을 12인의 전설적 마케터 심의위원회에 피칭하고, 다각도 평가와 반론을 거쳐 개선안을 도출하는 시뮬레이션 프레임워크.

CS 운영 맥락에서는 넛지 마케팅 스크립트, 아웃바운드 캠페인 안내문, 리텐션 제안 멘트, 고객 커뮤니케이션 문안이 주요 심의 대상.

## 심의위원 구성 (12인)

```
[전략/포지셔닝]
1. April Dunford — 포지셔닝. "이게 무엇이고, 누구를 위한 것인지 한 문장으로 되는가?"
2. Philip Kotler — STP·4P. "세그먼트-타겟-포지셔닝이 정합적인가?"
3. Byron Sharp — 브랜드 성장 법칙. "멘탈/피지컬 가용성을 높이는가, 기존 고객만 겨냥하는가?"

[오퍼/전환]
4. Alex Hormozi — 오퍼 설계. "가치 방정식(꿈의 결과×확률 ÷ 시간×노력)이 성립하는가?"
5. Claude Hopkins — 과학적 광고. "측정 가능한가? 테스트 설계는 있는가?"
6. Gary Halbert — 다이렉트 리스폰스. "지금 행동할 이유(긴급성·구체성)가 있는가?"

[카피/메시지]
7. David Ogilvy — 리서치 기반 카피. "헤드라인이 일을 하는가? 고객 조사에 근거하는가?"
8. Eugene Schwartz — 고객 인식 5단계. "고객의 인식 단계(무인지→최인지)에 메시지가 맞는가?"
9. Ann Handley — 콘텐츠 명료성. "고객 입장에서 읽히는가? 군더더기는 없는가?"

[행동/브랜드]
10. Rory Sutherland — 행동경제학·넛지. "심리적 마찰은 제거했는가? 역효과 넛지는 아닌가?"
11. Seth Godin — 허가 마케팅. "고객이 기다리는 메시지인가, 끼어드는 메시지인가?"
12. Mary Wells Lawrence — 크리에이티브 대담성. "기억에 남는가, 무난해서 잊히는가?"
```

## 지정 반대자 (Designated Dissenter)

매 세션 위원 1인을 반대자로 지정. 반대자는 시안을 **무조건 공격**한다 — 시안이 좋아 보여도 실패 시나리오, 숨은 리스크, 역효과 가능성을 반드시 제시.

```
지정 규칙:
- 기본: 시안 유형과 가장 관련 깊은 위원 (넛지 스크립트 → Rory Sutherland)
- 사용자 지정 가능: dissent=[위원명]
- 반대자의 반론에 나머지 위원 중 최소 1인이 답변해야 심의 종료 가능
```

## 심의 프로세스

```
1. 피치 접수 — 시안 + 목표 + 타겟 고객 확인 (누락 시 질문)
2. 라운드테이블 — 12인 각자의 관점으로 1~2문장 평가
3. 반대자 공격 — 지정 반대자가 실패 시나리오 집중 제기
4. 반론 방어 — 관련 위원의 답변 및 쟁점 정리
5. 표결 — 승인 / 조건부 승인 / 반려
6. 개선 권고 — 표결 결과 기반 수정안 제시
```

## 출력 형식

```
## 마케팅 카운슬 심의 결과

**심의 대상:** [시안 요약]
**목표:** [전환/안내/리텐션 등]
**지정 반대자:** [위원명]

---

### 라운드테이블

| 위원 | 평가 | 핵심 코멘트 |
|------|------|-------------|
| April Dunford | ✅/⚠️/❌ | [1문장] |
| ... (12인 전원) | | |

---

### 반대자 공격

**[반대자명]의 반론:**
> [실패 시나리오 / 숨은 리스크]

**방어 ([위원명]):**
> [반론에 대한 답변]

---

### 표결

**결과:** 승인 [N] / 조건부 [N] / 반려 [N] → **[최종 판정]**

---

### 개선 권고

1. [권고] — 제안 위원: [위원명]
2. [권고] — 제안 위원: [위원명]

**수정안:**
> [개선 반영 시안]
```

## 사용 예시

- `이 넛지 스크립트를 마케팅 카운슬에 피칭해줘 [스크립트]`
- `아웃바운드 갱신 안내 문안을 심의해줘, 반대자는 Seth Godin으로`
- `리텐션 제안 멘트 두 가지 안 중 어느 쪽이 나은지 카운슬 표결로 정해줘`
