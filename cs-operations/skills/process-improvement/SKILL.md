# 프로세스 개선 (Process Improvement)

CS 운영 프로세스의 비효율을 진단하고 개선 로드맵을 수립하는 프레임워크.

## 진단 프레임워크

### 7가지 낭비 (CS 버전)
```
1. 과잉 처리: 불필요하게 복잡한 처리 절차
2. 대기: 승인/이관/시스템 응답 대기
3. 이동: 불필요한 이관, 재연결, 반복 확인
4. 재작업: 오류로 인한 재처리
5. 재고: 미처리 VOC/작업 적체
6. 과잉 동작: 상담사 불필요 클릭/단계
7. 불량: 오안내, 잘못된 처리
```

## 출력 형식

ALWAYS use this exact template:
