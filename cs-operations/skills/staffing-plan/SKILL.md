# 인력 배치 계획 (Staffing Plan)

콜 볼륨과 서비스수준 목표를 기반으로 최적 인력 배치를 도출하는 프레임워크.

## 배치 원칙

```
[서비스수준 기준]
- 목표: 20초 내 응대율 80% 이상
- 여유율: 15-20% (이탈/교육/휴게)

[스킬 기반 배치]
- 복잡 문의: 시니어 배치 우선
- 고령자 많은 시간대: 인내심/경험 고려
- 신규 입사자: 1:3 OJT 비율
```

## 출력 형식

ALWAYS use this exact template:

```
## 인력 배치 계획

**기준 기간:** [기간]  
**총 인원:** [N]명

---

### 시간대별 배치 계획

| 시간대 | 예상 콜볼륨 | 필요 인원 | 배치 인원 | 여유율 |
|--------|------------|-----------|-----------|--------|
| 09-11시 (피크) | [N] | [N] | [N] | [%] |
| 11-13시 | [N] | [N] | [N] | [%] |
| 13-15시 (피크) | [N] | [N] | [N] | [%] |
| 15-18시 | [N] | [N] | [N] | [%] |
| 18-20시 | [N] | [N] | [N] | [%] |

---

### 요일별 조정

**고볼륨 요일 (월/화):** [조치]  
**저볼륨 요일 (금/토):** [교육/코칭 활용]

---

### 특수 배치 사항

| 사항 | 기간 | 조치 |
|------|------|------|
| 신규 입사자 OJT | | |
| 집중 교육 | | |
| 피크 이벤트 대응 | | |

---

### 서비스수준 예측

예상 달성률: [%] (목표: 80%)  
리스크 시간대: [시간대]  
대응 방안: [방안]
```

## 사용 예시

- `다음 주 인력 배치 계획을 수립해줘. 월요일 피크 예상`
- `신규 입사자 3명 포함한 팀 배치 계획을 만들어줘`
- `피크 시즌 서비스수준 유지를 위한 인력 계획을 세워줘`
