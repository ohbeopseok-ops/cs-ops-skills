# JOYLAB Content Team Skill

URL 1개 → JOYLAB 6개 플랫폼 콘텐츠 자동 생성.

---

## 실행 흐름 개요

```
STEP 1  URL 파싱 & 콘텐츠 추출
STEP 2  brief.md 생성 (planner)
STEP 3  6개 에이전트 병렬 실행
         ├─ OUTPUT A: 네이버 블로그 포스팅 (SEO 최적화)
         ├─ OUTPUT B: Tistory 포스팅 (AdSense 최적화)
         ├─ OUTPUT C: Threads 스레드 10개
         ├─ OUTPUT D: 유튜브 리뷰 대본
         ├─ OUTPUT E: 뉴스레터 초안
         └─ OUTPUT F: 쇼츠 대본 3개
STEP 4  reviewer 검수 → review-report.md
```

---

## STEP 1 — URL 파싱 & 콘텐츠 추출

### 입력 형식

```
/content https://www.youtube.com/watch?v=VIDEO_ID
/content https://example.com/blog/article
```

### URL 타입 분기

| 타입 | 처리 방식 |
|------|-----------|
| YouTube | web_fetch로 제목·설명 추출 + 검색으로 내용 보완 |
| 블로그/뉴스 | web_fetch로 본문 전체 추출 |
| 기타 웹페이지 | web_fetch로 주요 텍스트 추출 |

### 추출 데이터 구조

```json
{
  "source_type": "youtube | blog | web",
  "source_url": "",
  "source_title": "",
  "extract_date": "YYYY-MM-DD",
  "raw_content": "",
  "key_messages": [],
  "target_keywords": [],
  "content_category": "AI | 투자/ETF | CS운영 | 기술 | 기타",
  "estimated_audience": ""
}
```

---

## STEP 2 — brief.md 생성 (Planner 역할)

추출 데이터를 기반으로 `brief.md` 작성.
모든 에이전트가 이 파일을 참조한다.

### brief.md 포맷

```markdown
# JOYLAB Content Brief — [날짜]

## 소스 정보
- URL: [원본 URL]
- 제목: [원본 제목]
- 카테고리: [AI | 투자/ETF | CS운영 | 기술]

## 핵심 메시지 (3~5개)
1. [핵심 포인트 1]
2. [핵심 포인트 2]
3. [핵심 포인트 3]

## 타겟 독자
[JOYLAB 주요 독자층: 1인 창업가 / AI 관심자 / CS 실무자 / 투자 입문자]

## 플랫폼별 각색 포인트
- 네이버 블로그: SEO 키워드, C-Rank 최적화 방향
- Tistory: AdSense 클릭 유도 구조, 검색 유입 키워드
- Threads: 후킹 문장, 대화 유도 포인트
- 유튜브: 영상 구성 타임라인 제안
- 뉴스레터: 깊이 있는 해설 포인트
- 쇼츠: 60초 핵심 메시지 3개

## 금지 표현
- AI틱 표현: "혁신적인", "획기적인", "놀라운"
- 불확실한 주장: "~것 같습니다"
- 과장: 구체적 수치로 대체

## 브랜드 톤
- 담백하고 직관적
- 숫자+근거 병기
- "써보고 씁니다" / "만들어서 씁니다" 오실장 정체성 유지
```

## STEP 3 — 6개 에이전트 출력

---

### OUTPUT A: 네이버 블로그 포스팅

**파일명**: `naver_blog_[날짜].md`

**스펙**:
- 분량: 2,000~3,500자
- 구조: 도입(후킹) → 본론 3~4섹션 → 결론(CTA 1개)
- SEO: 제목에 핵심 키워드 포함, 소제목 H2/H3 활용
- C-Rank 최적화: 첫 문단에 핵심 정보 배치, 체류시간 유도 구조

**오실장 페르소나 규칙**:
- 숫자+출처 병기
- 신뢰도 등급: 🟢 직접 확인 / 🟡 출처 있음 / ⚠️ 추정
- "이 가설이 틀릴 조건" 블록 포함 (AI/투자 글 한정)
- CTA: 유튜브 채널 구독 1개만
- 마무리: "선택하라 / 준비하라 / 시작하라" 동사

**포맷**:

```markdown
# [SEO 제목 — 30자 이내, 핵심 키워드 포함]

[후킹 첫 문장 — 숫자 또는 반전으로 시작]

## [소제목 1]
[본문]

## [소제목 2]
[본문]

## [소제목 3]
[본문]

> ⚠️ 이 글이 틀릴 조건: [반증 가능 조건 1~2개]

## 마무리
[오실장 코멘트 + CTA]

---
※ 이 글은 정보 제공 목적이며 투자 권유가 아닙니다. (투자 글 한정)
```

---

### OUTPUT B: Tistory 포스팅

**파일명**: `tistory_[날짜].md`

**스펙**:
- 분량: 1,500~2,500자
- AdSense 최적화: 본문 내 자연스러운 단락 구분 (광고 삽입 공간)
- 검색 유입 키워드 전략: 롱테일 키워드 소제목 활용
- 네이버 블로그와 30% 이상 다른 구성

**포맷**:

```markdown
# [Tistory 제목 — 검색 의도 반영]

[도입 — 검색자의 궁금증 직접 해소]

## [소제목 1 — 롱테일 키워드]
[본문]

<!-- AdSense 광고 위치 -->

## [소제목 2]
[본문]

## 핵심 요약
- [포인트 1]
- [포인트 2]
- [포인트 3]

[마무리 + 관련 포스팅 내부 링크 제안]
```

---

### OUTPUT C: Threads 스레드

**파일명**: `threads_[날짜].md`

**스펙**:
- 10개 포스트 시리즈
- 각 500자 이내 (Threads 제한)
- 구조: 후킹 → 본론 7~8개 → 마무리 + CTA
- 첫 번째가 팔로우를 만드는 문장

**포맷**:

```
[1/10] 후킹 — 숫자 또는 역설로 시작
→ 이어 읽게 만드는 마지막 문장

[2/10] 핵심 포인트 1
→ ...

...

[10/10] 마무리 + CTA
→ "더 자세한 내용은 블로그/유튜브에서"
```

---

### OUTPUT D: 유튜브 리뷰 대본

**파일명**: `youtube_script_[날짜].md`

**스펙**:
- 분량: 7~12분 분량 (A4 4~6장)
- 타임스탬프 포함
- 오프닝 후킹 15초 필수
- 화면 구성 지시 포함 [화면: xxx]

**포맷**:

```markdown
# [유튜브 영상 제목]

## 영상 정보
- 예상 시간: X분
- 썸네일 메인 텍스트: [2줄]
- 태그: [키워드 5~7개]

---

## 대본

### 오프닝 (0:00~0:15)
[화면: 썸네일 이미지]
"[후킹 문장 — 시청자가 영상을 끝까지 볼 이유]"

### 섹션 1 — [소제목] (0:15~X:XX)
[화면: xxx]
[대본]

### 섹션 2 — [소제목] (X:XX~X:XX)
...

### 마무리 + CTA (X:XX~끝)
"구독과 좋아요는 더 좋은 콘텐츠를 만드는 힘이 됩니다."
```

---

### OUTPUT E: 뉴스레터 초안

**파일명**: `newsletter_[날짜].md`

**스펙**:
- 분량: 1,000~1,500자 (이메일 최적)
- 구조: 인사말 → 이번 주 핵심 인사이트 → 실용 팁 1개 → CTA
- 오실장 구독자 대상, 친근한 "요"체

**포맷**:

```markdown
# [뉴스레터 제목]

안녕하세요, 오실장입니다.

이번 주 핵심 한 줄:
> "[핵심 인사이트 1문장]"

## 이번 주 다룰 내용
[3~4문단 본론]

## 바로 써먹는 팁
[실용적인 액션 아이템 1~2개]

## 마무리
[짧은 클로징 + 다음 호 예고]

---
*[구독 해지 안내] | [JOYLAB 링크트리]*
```

---

### OUTPUT F: 쇼츠 대본 3개

**파일명**: `shorts_scripts_[날짜].md`

**스펙**:
- 각 60초 (150~200자 기준)
- 구조: 후킹(0~5초) → 본론(5~50초) → CTA(50~60초)
- 3개는 각각 다른 각도에서 접근

**포맷**:

```
--- 쇼츠 #1: [제목] ---
[0:00~0:05] 후킹
"[시청자를 멈추게 하는 첫 문장]"

[0:05~0:50] 본론
[화면: xxx]
"[핵심 내용]"

[0:50~1:00] CTA
"구독하면 이런 내용 매주 받아볼 수 있어요"

--- 쇼츠 #2: [제목] ---
...

--- 쇼츠 #3: [제목] ---
...
```

## STEP 4 — Reviewer 검수

**파일명**: `review_report_[날짜].md`

### 검수 항목

| 항목 | 기준 |
|------|------|
| 브랜드 톤 일관성 | "써보고 씁니다" 오실장 정체성 유지 여부 |
| 팩트 정확성 | 원본 소스 대비 왜곡·과장 여부 |
| AI틱 표현 | "혁신적", "획기적", "놀라운" 등 금지 표현 사용 여부 |
| 플랫폼 스펙 | 각 플랫폼 글자수·구조 준수 여부 |
| 한국어 자연스러움 | 번역 투·AI 투 문장 여부 |
| CTA 중복 | 플랫폼당 CTA 1개 초과 여부 |

### 검수 리포트 포맷

```markdown
# 검수 리포트 — [날짜]

## 전체 판정: [통과 | 수정 필요]

## 출력물별 검수

### OUTPUT A (네이버 블로그)
- 판정: [통과 | 수정]
- 이슈: [있으면 기술]

### OUTPUT B (Tistory)
...

## 수정 요청 사항
- [수정 필요 항목 및 이유]

## 최종 승인
[검수 완료 시 승인 도장]
```

| 출력물 | 파일명 | 형식 |

```
/content [URL]

멀티플랫폼 콘텐츠 패키지 [URL]
이 영상 콘텐츠로 만들어줘: [URL]
```

## 주의사항

- 집 환경 전용 (web_fetch, web_search 필수)
- Claude Code에서는 `.claude/agents/` 파일이 subagent 자동 호출 조건
- 브리프 먼저 생성 → 병렬 실행 순서 준수
- 투자/금융 콘텐츠: 면책 문구 필수
- 소요 시간: URL 추출 + 6종 생성 약 5~8분 예상
- 영상 다운로드/편집 (yt-dlp, ffmpeg)은 이 스킬 범위 외
  → 필요 시 별도 `joylab-video-maker` 스킬로 분리 예정
