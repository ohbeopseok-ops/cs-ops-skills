## 6. 한계와 판단 기준 (정직성)
1. **영상 자료 미반영** — §2. 자료를 확보하면 `docs/REUSE_ANALYSIS.md` 에 비교표를 추가하고 테마를 보강한다.
2. **환경 한계** — Linux 헤드리스 Chrome 1종. Windows/macOS Chrome·Edge·Safari, 실제 프로젝터 전체화면, 실제 인쇄 대화상자는 미검증.
3. **시각 검토 범위** — HTML 3테마 45장 전부를 축소 컨택트 시트로, 일부는 원본 해상도로 눈으로 확인. 미세한 줄바꿈 취향은 사람 검토 필요.
4. **QA 기준 선택(내가 정한 것)**: 안전영역 36px(상단·하단 소폭 완화), 보이는 overflow 4px 허용(글리프 박스 오차), 알파 0.3 미만 반투명 장식은 텍스트와 겹쳐도 허용, 숫자 출처 검사는 0–15(쪽·순번)와 차트 눈금 숫자를 허용. 기준을 바꾸면 결과가 달라질 수 있다.
5. **QA 수정 이력** — 1차 실행 FAIL 17건 중 실제 결함 5건(§ CHANGELOG), 검사 코드 오류 4건(숫자 합침, 의사요소 스크롤 오탐, 선언 순서, 수정 미적용). 이후 구조 문제 1건 추가 수정. 최종 재실행에서 FAIL 0.
6. **자체 검증** — 10/10 포착. M10(겹침)은 1차 변이(-120px)가 실제 겹침을 만들지 못해 미포착이었고, -330px 로 강화 후 포착(`selftest_results.json` 에 기록). 즉 "1차에 놓쳤다"는 사실을 숨기지 않는다.
7. **덱 내용 근거** — 사실 배지 슬라이드는 프로젝트 운영 지침 §7·§8 에서 가져왔다. 지침은 "최신 승인 자료 우선"이므로 **승인본과 대조 필요**. 사례·대사·차트 값은 전부 `[가상]` 이며 성과 근거가 아니다.
8. **PPTX 표기** — 출처 줄에 `[가정·가상] [가상] …` 처럼 태그가 중복되는 슬라이드가 있음(미수정, 외형 결함).
9. **폰트** — Pretendard 서브셋은 KS X 1001 한글 2,350자 + 기호. 범위 밖 글자는 시스템 폰트 대체(QA T2 가 현재 덱에서 0자 확인).
10. **창작 수치 탐지(D5)** 는 숫자 토큰 출처만 본다. 문장 의미의 사실 여부는 검사하지 않는다.

```
git diff --stat origin/main...HEAD -- . ':!cs-presentation'   # 기존 파일 변경 없음 확인(출력 비어야 함)
```
