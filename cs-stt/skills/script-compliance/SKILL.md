# 스크립트 준수율 분석 (Script Compliance)

상담 스크립트 준수 여부를 체계적으로 점검하고 통계화하는 프레임워크.

## 준수율 분석 항목

```
[필수 인사 스크립트] — 가중치 30%
- 오프닝: "LG U+ [이름]입니다" 형태 준수
- 클로징: 감사 인사 + 추가 문의 확인

[처리 프로세스 스크립트] — 가중치 40%
- 본인 확인 절차 이행
- 보류 전 양해 요청
- 처리 결과 안내

[서비스 안내 스크립트] — 가중치 30%
- 필수 안내 사항 (상품별 상이)
- 주의/약관 고지 (해당 시)
```

## 출력 형식

ALWAYS use this exact template:

```
## 스크립트 준수율 분석

**분석 기간:** [기간]  
**분석 건수:** [N]건  
**대상:** [전체 / 특정 상담사/팀]

---

### 전체 준수율

| 항목 | 준수 건수 | 전체 건수 | 준수율 | 목표 | 상태 |
|------|-----------|-----------|--------|------|------|
| 필수 인사 스크립트 | [N] | [N] | [%] | [%] | 🔴/🟡/🟢 |
| 처리 프로세스 | [N] | [N] | [%] | [%] | |
| 서비스 안내 | [N] | [N] | [%] | [%] | |
| **종합 준수율** | | | **[%]** | [%] | |

---

### 항목별 미준수 패턴

| 미준수 항목 | 빈도 | 주요 패턴 |
|-------------|------|-----------|
| [항목] | [N]건 | [어떻게 생략/변형되는가] |

---

### 상담사별 준수율 (해당 시)

| 상담사 | 준수율 | 주요 미준수 항목 | 조치 |
|--------|--------|-----------------|------|
| [이름] | [%] | [항목] | [코칭/교육] |

---

### 개선 권고

**즉시 집중:** [가장 낮은 준수율 항목]  
**교육 방향:** [미준수 패턴 기반 교육 내용]  
**재측정 일정:** [날짜]
```

## 사용 예시

- `이번 주 상담 20건의 스크립트 준수율을 분석해줘`
- `클로징 스크립트 누락 패턴을 팀별로 분석해줘`
- `신규 스크립트 도입 전후 준수율 변화를 비교해줘`
