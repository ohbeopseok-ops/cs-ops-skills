# STT 대화 분석 (Conversation Analysis)

고객-상담사 STT 대화 텍스트를 다각도로 분석하는 종합 프레임워크.

## 분석 차원

### 1. 대화 구조 분석
- 발화 비율: 고객 vs 상담사 (이상적 = 60:40 또는 50:50)
- 침묵 구간: 5초 이상 침묵 횟수/위치
- 대화 흐름: 문제 파악 → 해결 → 종결 구조 준수 여부

### 2. 감성 분석
```
고객 감성 추이:
- 시작: [부정/중립/긍정]
- 중반: [변화 여부]
- 종결: [최종 감성]

감성 변곡점: 어느 발화에서 감성이 변했는가
```

### 3. 핵심 이슈 추출
- 주요 문의 유형 태깅
- 고객 Pain Point Top 3
- 미해결 이슈 여부

### 4. 상담사 행동 패턴
- 공감 표현 빈도/자연스러움
- 해결책 제시 명확성
- 클로징 완결성

### 5. 리스크 신호
```
HIGH: 고객 격앙, 법적 언급, 해지 언급
MEDIUM: 재질문 반복, 불만 표현
LOW: 아쉬움 표현, 미약한 불만
```

## 대화 텍스트 입력 형식

```
[시간] 고객: [발화]
[시간] 상담사: [발화]
```
또는 순수 텍스트도 분석 가능 (화자 구분이 없을 경우 추정)

## 출력 형식

ALWAYS use this exact template:

```
## STT 대화 분석 결과

**상담 시간:** [N]분 [N]초  
**콜 유형:** [추정/확인]  
**상담사:** [이름/ID]

---

### 대화 구조

발화 비율: 고객 [%] : 상담사 [%]  
침묵 구간: [N]회 ([총 N]초)  
대화 흐름: [정상 / 이탈 — 이탈 구간: [시점]]

---

### 감성 분석

**고객 감성 추이:**
시작 → 중반 → 종결
[부정/중립/긍정] → [변화] → [최종]

**감성 변곡점:**
> [시점]: "[발화 인용]" → [감성 변화 방향]

**종결 만족도 예측:** [만족/중립/불만] (신뢰도: [높음/중간])

---

### 핵심 이슈

**주요 문의:** [이슈 태그]

**고객 Pain Point:**
1. [Pain Point] — "[관련 발화]"
2. [Pain Point] — "[관련 발화]"
3. [Pain Point] (해당 시)

**처리 결과:** [완결 / 부분 해결 / 미해결]  
**미해결 이슈:** [있음 — 내용 / 없음]

---

### 상담사 행동 패턴

| 항목 | 평가 | 근거 |
|------|------|------|
| 공감 표현 | [충분/부족/과도] | "[발화]" |
| 문제 파악 | [신속/보통/지연] | |
| 해결책 명확성 | [명확/모호] | |
| 클로징 완결 | [완결/미완결] | |

---

### 리스크 신호

**레벨:** [HIGH / MEDIUM / LOW / 없음]

| 신호 | 내용 | 발화 |
|------|------|------|
| [유형] | [내용] | "[발화]" |

---

### 개선 포인트

**잘한 점:** [구체적 발화/행동]  
**개선 필요:** [구체적 발화/행동] → [권장 대안]  
**우선 코칭 항목:** [항목]
```

## 사용 예시

- `이 STT 텍스트를 전체 분석해줘: [텍스트]`
- `고객 감성 변화와 리스크 신호를 중심으로 분석해줘`
- `해지 위험 대화 패턴을 탐지해줘`
