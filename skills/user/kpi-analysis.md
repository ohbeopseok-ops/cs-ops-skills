# KPI 분석 프레임워크 (KPI Analysis)

홈CS 운영 KPI 체계 기반 현황 진단 및 원인 분석 프레임워크.

## KPI 체계

### Tier 1: 핵심 성과 지표 (경영 KPI)
```
T-NPS (전화 고객 순추천지수) — 최우선
FCR (First Call Resolution, 1콜 해결률)
서비스 수준 (SLA: 20초 내 응대율)
```

### Tier 2: 운영 품질 지표
```
QA 평균 점수 / 등급 분포
AHT (Average Handle Time)
이탈률 (포기율)
상담사 만족도 (eNPS)
```

### Tier 3: 효율 지표
```
생산성 (콜 처리 건수/인/시간)
전산 처리 오류율
이관률
재연결률 (3일 내 재접촉)
```

## KPI 분석 프레임워크

### 1단계: 현황 스코어카드
- 목표 대비 달성률 (%)
- 전월 대비 변화 (△)
- 전년 동기 대비 변화

### 2단계: 원인 진단 (5-Why)
- KPI 미달 지표 → 1차 원인 → 근본 원인
- 상관관계 분석: T-NPS ↔ FCR ↔ QA 연관성

### 3단계: 개선 레버 식별
- 단기 레버 (1-2주 내 조치 가능)
- 중기 레버 (1개월 내)
- 구조적 레버 (시스템/프로세스 개선)

- `이번 달 KPI 데이터로 스코어카드와 원인 분석을 해줘`

- `다음 달 KPI 목표 달성을 위한 핵심 레버를 찾아줘`
