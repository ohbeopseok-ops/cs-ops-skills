# 감성 분석 (Sentiment Analysis)

고객 텍스트에서 감성 패턴을 탐지하고 운영 인사이트를 도출하는 프레임워크.

## 감성 분류 체계

### 극성 분류
```
강한 부정 (-2): 격앙, 폭언, 법적 위협, 해지 언급
약한 부정 (-1): 불만, 실망, 답답함, 아쉬움
중립    (0):  사실 전달, 확인 요청
약한 긍정 (+1): 만족, 고마움, 이해
강한 긍정 (+2): 매우 만족, 칭찬, 추천 의향
```

### CS 특화 감성 키워드

불만 시그널:
- "이게 말이 됩니까", "환불", "해지", "신고", "소비자원"
- "몇 번을 전화해야", "매번 이렇게", "처음부터 다시"

만족 시그널:
- "감사합니다", "잘 해결됐어요", "친절하시네요"
- "다음에 또 연락할게요"

## 출력 형식

ALWAYS use this exact template:

```
## 감성 분석 결과

**분석 대상:** [STT 텍스트 / VOC N건]  
**분석 일시:** [날짜]

---

### 감성 분포

| 감성 | 건수/비율 | 강도 분포 |
|------|-----------|-----------|
| 강한 부정 (-2) | [N] ([%]) | |
| 약한 부정 (-1) | [N] ([%]) | |
| 중립 (0) | [N] ([%]) | |
| 약한 긍정 (+1) | [N] ([%]) | |
| 강한 긍정 (+2) | [N] ([%]) | |

**평균 감성 점수:** [-2 ~ +2]  
**부정 비율:** [%] (주의 기준: 30% 이상)

---

### 핵심 감성 키워드

부정 키워드 Top 5: [키워드1] ([N]회), [키워드2], ...  
긍정 키워드 Top 5: [키워드1], ...

---

### 위험 발화 탐지

| 발화 | 감성 | 위험 유형 | 우선 조치 |
|------|------|-----------|-----------|
| "[발화 일부]" | -2 | [해지/신고/법적] | [조치] |

---

### 인사이트

**감성 트렌드:** [전기 대비 변화]  
**주요 불만 맥락:** [어떤 상황에서 부정 감성 발생]  
**개선 권고:** [감성 개선을 위한 조치]
```

## 사용 예시

- `이번 주 VOC 50건의 감성을 분석해줘`
- `STT 텍스트에서 위험 발화를 탐지해줘`
- `부정 감성 증가 원인과 패턴을 분석해줘`
