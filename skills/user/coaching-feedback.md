# 코칭 피드백 작성 (Coaching Feedback)

SBI 모델과 성장 중심 접근으로 실행 가능한 코칭 피드백을 구조화하는 프레임워크.

## 코칭 원칙

**SBI 모델:**
- **S (Situation)**: 언제, 어떤 상황에서
- **B (Behavior)**: 구체적으로 어떻게 행동했는지
- **I (Impact)**: 그 결과 어떤 영향이 있었는지

**코칭 접근 방식:**
- 비판이 아닌 관찰: "잘못했다"가 아닌 "이렇게 했다"
- 행동 중심: 성격이 아닌 구체적 행동에 초점
- 대안 제시: 문제 지적 후 반드시 권장 행동 제시
- 강점 먼저: 개선점 전에 잘한 점 2가지 이상

## 코칭 유형별 접근

**강점 코칭 (S등급, 우수 행동):**
→ 구체적 칭찬 + 확산 요청 ("이 방법을 팀원들과 공유해주세요")

**개선 코칭 (취약 항목 집중):**
→ SBI + 대안 발화 예시 + 연습 방법 제시

**위기 코칭 (D등급, 즉각 개입):**
→ 원인 탐색 질문 + 즉시 실행 계획 + 후속 확인 일정

## 코칭 피드백 출력 형식

ALWAYS use this exact template:

```
## 코칭 피드백 시트

**상담사:** [이름] / [팀]  
**코칭 일자:** [날짜]  
**코칭 유형:** [정기 / 집중 / 긴급]  
**평가 기준 콜:** [N]건 ([기간])

---

### 현재 수준

| 지표 | 현재 | 팀 평균 | 목표 |
|------|------|---------|------|
| 종합 점수 | [점] | [점] | [점] |
| 등급 | [등급] | | |
| 취약 항목 | [항목] | | |

---

### 잘하고 있는 것 (강점 2가지)

**1. [강점 제목]**
- 상황: [언제, 어떤 상황에서]
- 행동: "[구체적 발화 또는 행동]"
- 영향: [고객/팀에 미친 긍정적 영향]

**2. [강점 제목]**
- 상황: [상황]
- 행동: "[발화/행동]"
- 영향: [영향]

---

### 개선이 필요한 것 (핵심 1-2가지)

**1. [개선 항목]**
- 상황: [언제, 어떤 상황에서]
- 현재 행동: "[실제 발화/행동]"
- 영향: [고객에게 미친 부정적 영향]
- 권장 행동: "[대체 발화/행동 예시]"
- 연습 방법: [구체적 연습 방법]

**2. [개선 항목]** (해당 시)
- 상황:
- 현재 행동:
- 영향:
- 권장 행동:

---

### 실행 계획

| 항목 | 목표 | 방법 | 확인 일자 |
|------|------|------|-----------|
| [취약 항목1] | [목표 수준] | [방법] | [날짜] |
| [취약 항목2] | [목표 수준] | [방법] | [날짜] |

---

### 코칭 질문 (대화 유도용)

1. "[강점 관련 질문 — 자신감 강화]"
2. "[개선점 관련 질문 — 자기 인식 유도]"
3. "[목표 관련 질문 — 동기 부여]"

---

**코칭어 서명:** [팀장 이름] / [상담사 서명]  
**다음 코칭 일정:** [날짜]
```

## 사용 예시

- `QA 점수 72점 상담사 홍길동의 코칭 피드백을 작성해줘. 취약 항목: 문제 파악, 스크립트 준수`
- `이번 주 D등급 2명의 긴급 코칭 자료를 만들어줘`
- `S등급 우수 상담사 강점 코칭 피드백을 작성해줘`
