# 넛지 마케팅 분석 (Nudge Analysis)

CS 상담 내 넛지 마케팅 효과를 측정하고 최적화하는 분석 프레임워크.

## 넛지 유형 분류

```
[인바운드 연계 넛지]
- 문의 해결 후 연계 안내
- 고객 상황 기반 맞춤 제안
- 불만 해소 후 리텐션 제안

[아웃바운드 넛지]
- 사전 안내성 아웃바운드
- 갱신/업그레이드 안내
- 만족도 확인 연계 제안

[디폴트 옵션 넛지]
- "자동 갱신이 기본입니다, 변경 원하세요?"
- 기본 설정 안내
```

## 넛지 성공 판정 기준
```
성공: 고객이 제안을 수용 (동의/가입/유지)
부분: 추가 검토 의향 표명
실패: 거절
이탈: 불만으로 연결 (역효과)
```

## 출력 형식

ALWAYS use this exact template:

```

**분석 기간:** [기간]  
**넛지 시도 건수:** [N]건

---

### 성공률 현황

| 넛지 유형 | 시도 | 성공 | 성공률 | 전기 대비 |
|-----------|------|------|--------|-----------|
| 인바운드 연계 | [N] | [N] | [%] | [△] |
| 아웃바운드 | [N] | [N] | [%] | [△] |
| 디폴트 옵션 | [N] | [N] | [%] | [△] |
| **전체** | | | **[%]** | |

---

### 효과적 넛지 타이밍

**성공률 높은 조건:**
1. [조건] — 성공률 [%]
2. [조건] — 성공률 [%]

**피해야 할 타이밍:**
1. [조건] — 역효과 위험

---

### 우수 넛지 발화 패턴

> "[성공 사례 발화 패턴]"

```

## 사용 예시

- `이번 달 넛지 마케팅 상담 결과를 분석해줘`
- `아웃바운드 넛지 스크립트 효과를 측정해줘`
- `성공률이 높은 넛지 타이밍 패턴을 찾아줘`
