# 코칭 세션 스크립트 (Coaching Script)

코칭 목적과 상담사 상태에 맞는 실전 코칭 대화 가이드 생성 프레임워크.

## 코칭 세션 구조 (45분 기준)

```
[도입 — 5분]
분위기 조성 + 오늘 코칭 목적 공유

[현황 공유 — 10분]
데이터 기반 현재 수준 공유 (비판 없이)

[원인 탐색 — 10분]
열린 질문으로 상담사 스스로 원인 발견 유도

[해결책 수립 — 10분]
상담사 주도 개선 방안 도출 + 코치 보완

[실행 계획 합의 — 7분]
구체적 목표 + 방법 + 확인 일정 합의

[마무리 — 3분]
격려 + 다음 코칭 일정 확인
```

## 코칭 단계별 대화 가이드

### 도입 질문 (분위기 조성)
```
"요즘 상담하면서 어떤 점이 가장 어렵게 느껴지세요?"
"최근 기억에 남는 상담이 있으면 이야기해줄 수 있어요?"
"오늘 코칭에서 어떤 도움을 받으면 좋겠어요?"
```

### 현황 공유 (데이터 제시)
```
"지난 2주 평가 결과를 같이 보면서 이야기해요."
"전체적으로 [N]점인데, 어떻게 생각하세요?"
"특히 [취약 항목]이 [점수]점인데, 본인은 어떻게 느끼셨어요?"
```

### 원인 탐색 질문 (열린 질문)
```
"그 상황에서 어떤 생각이 드셨어요?"
"[취약 항목]이 어려운 이유가 뭐라고 생각해요?"
"그때 다르게 했다면 어떻게 할 수 있었을까요?"
```

### 저항 상담사 대응
```
상담사: "평가 기준이 이상한 것 같아요"
→ "어떤 부분이 납득이 안 되는지 구체적으로 이야기해줄래요?"

상담사: "저만 이런 게 아니잖아요"
→ "맞아요, 팀 전체 이슈이기도 해요. 그래서 [이름]님이 먼저 개선하면 팀에 도움이 되죠."

상담사: (침묵)
→ "바로 답하기 어려우면 괜찮아요. 제가 관찰한 걸 먼저 이야기할게요."
```

## 코칭 스크립트 출력 형식

ALWAYS use this exact template:

```
## 코칭 세션 스크립트

**상담사:** [이름] / [등급] / [취약 항목]  
**코칭 유형:** [강점 강화 / 취약 개선 / 위기 개입]  
**예상 소요 시간:** [N]분

---

### 도입 (5분)

팀장: "[이름]씨, 오늘 시간 내줘서 고마워요. 오늘은 [핵심 목적]에 대해 이야기하려고 해요.
       최근 상담 어때요? 힘든 점이 있으면 편하게 이야기해줘요."

기대 응답: [예상 응답 패턴]  
분기 처리:
- 긍정적 → "[다음 발화]"
- 부정적/저항 → "[대응 발화]"

---

### 현황 공유 (10분)

팀장: "지난 [기간] 평가 결과예요. [취약 항목]이 [점수]점인데 보이시죠?
       이 부분에 대해 어떻게 생각하세요?"

[데이터 제시 방법: 수치만, 비교 없이, 비난 없이]

상담사 반응별 대응:
- "몰랐어요" → "[공감 + 구체적 사례 제시]"
- "알고 있었어요" → "[인식 확인 + 원인 탐색으로 이동]"
- "기준이 이상해요" → "[기준 설명 + 공감 + 전환]"

---

### 원인 탐색 (10분)

팀장 질문 1: "[열린 질문]"
팀장 질문 2: "[심화 질문]"
팀장 질문 3: "[자기 인식 유도 질문]"

[핵심: 답을 주지 말고 질문으로 스스로 발견하게]

---

### 해결책 수립 (10분)

팀장: "[이름]씨가 말한 것처럼 [원인]이 맞다면, 어떻게 하면 좋을까요?"

상담사 제안 수용 후 보완:
"좋은 방법이에요. 거기에 하나 더하면 [보완책]도 효과적일 것 같아요."

권장 대체 발화 제시:
현재: "[현재 발화 패턴]"
권장: "[개선된 발화 예시]"

---

### 실행 계획 합의 (7분)

팀장: "그럼 다음 2주 동안 뭘 해볼까요? 구체적으로 정해봐요."

합의 내용:
1. [목표]: [측정 방법] / [달성 기한]
2. [활동]: [빈도] / [담당]
3. 다음 코칭: [날짜]

---

### 마무리 (3분)

팀장: "[이름]씨, 오늘 솔직하게 이야기해줘서 고마워요.
       [강점]은 계속 유지하고, [개선 항목]만 집중하면 충분히 [목표 등급] 갈 수 있어요.
       [날짜]에 다시 이야기해요."
```

## 사용 예시

- `QA 68점, 취약 항목: 경청/공감, 스크립트 준수인 상담사 코칭 스크립트를 만들어줘`
- `저항형 상담사 코칭 시나리오를 작성해줘`
- `신임 팀장용 코칭 세션 가이드를 만들어줘`
