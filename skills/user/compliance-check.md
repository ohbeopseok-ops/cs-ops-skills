# 스크립트 및 규정 준수 점검 (Compliance Check)

상담 내용의 필수 준수 항목과 금지 항목을 체계적으로 점검하는 프레임워크.

## 점검 항목 구조

### 필수 이행 멘트 (누락 시 감점)
```
[통화 시작]
- 소속/이름 안내: "LG U+ [부서] [이름]입니다"
- 본인 확인 절차 이행

[처리 중]
- 보류 전 양해 요청
- 처리 소요 시간 안내 (30초 이상 시)

[통화 종료]
- 추가 문의 확인: "더 도와드릴 것이 있을까요?"
- 감사 인사 및 종료 멘트
```

### 금지 표현 목록
```
[절대 금지 — 즉시 불량]
- 개인정보 직접 발화 (주민번호, 계좌번호 등)
- 경쟁사 비방 표현
- 허위/과장 안내
- 욕설/비하 표현

[강력 주의 — 감점]
- "모르겠는데요", "잘 모릅니다" (대안 없이)
- "안 돼요", "불가능해요" (이유 설명 없이)
- "빨리", "얼른" (재촉 표현)
- "당연히", "그건 고객님 문제죠"
- "원래 그래요", "다 그렇게 해요"

[주의 — 권고]
- 과도한 사과 반복 ("죄송합니다" 5회 이상)
- 불확실한 단정 ("아마 될 겁니다" 등)
- 반말 또는 존댓말 혼용
```

## 점검 출력 형식

ALWAYS use this exact template:

```
## 규정 준수 점검 결과

**상담사:** [이름/ID]  
**점검 일시:** [날짜]

---

### 필수 멘트 이행 현황

| 멘트 항목 | 이행 | 발화 내용 | 판정 |
|-----------|------|-----------|------|
| 소속/이름 안내 | [O/X] | "[발화]" | [적합/부적합] |
| 본인 확인 | [O/X] | | |
| 보류 양해 | [O/X] | | |
| 추가 문의 확인 | [O/X] | | |
| 종료 인사 | [O/X] | | |

**필수 멘트 이행률:** [N]/5 ([%])

---

### 금지 표현 탐지

| 등급 | 표현 | 발화 내용 | 대체 권장 |
|------|------|-----------|-----------|
| 즉시 불량 | [표현] | "[발화]" | [대체 표현] |
| 강력 주의 | [표현] | "[발화]" | [대체 표현] |
| 주의 | [표현] | "[발화]" | [대체 표현] |

**금지 표현 탐지: [N]건**

---

### 종합 판정

**컴플라이언스 등급:** [PASS / WARNING / FAIL]

- PASS: 필수 멘트 100%, 금지 표현 0건
- WARNING: 필수 누락 1건 또는 주의 표현 존재
- FAIL: 즉시 불량 표현 또는 필수 누락 2건 이상

**조치 권고:** [기록 보존 / 코칭 필요 / 즉시 보고]
```

## 사용 예시

- `이 STT 텍스트에서 필수 멘트 누락과 금지 표현을 찾아줘`
- `이번 주 상담 20건의 컴플라이언스 준수율을 분석해줘`
- `금지 표현 탐지 결과를 상담사별로 정리해줘`
