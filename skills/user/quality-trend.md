# 품질 추이 분석 (Quality Trend)

시계열 품질 데이터를 분석해 패턴과 리스크를 조기에 파악하는 프레임워크.

## 분석 프레임워크

### 추세 분석 (Trend)
- 단기 추세: 최근 4주 이동평균
- 중기 추세: 3개월 방향성 (상승/하락/횡보)
- 전년 동기 대비 변화

### 패턴 분석 (Pattern)
- 요일별 품질 편차 (월~일)
- 시간대별 품질 편차 (피크 vs 오프피크)
- 월중 패턴 (초/중/말 차이)

### 이상 구간 탐지 (Anomaly)
- 평균 ± 2 표준편차 이탈 구간
- 급락 구간: 전주 대비 5점 이상 하락
- 급등 구간: 전주 대비 5점 이상 상승 (원인 파악 필요)

### 개선 효과 측정 (Impact)
- 코칭/교육 시행일 전후 비교
- 프로세스 변경 전후 비교
- 특정 이벤트와 품질 변화 연관성

## 예측 모델

단순 예측 (4주 이동평균 기반):
```
예측 점수 = (W-1 + W-2 + W-3 + W-4) / 4 ± 조정 계수
조정 계수 = 최근 추세 방향 × 0.3
```

리스크 신호:
- 🔴 고위험: 예측 점수 70 미만 또는 3주 연속 하락
- 🟡 주의: 예측 점수 70-79 또는 2주 연속 하락
- 🟢 양호: 예측 점수 80 이상

ALWAYS use this exact template:


## 사용 예시

- `지난 8주 품질 데이터로 추이를 분석하고 다음 주를 예측해줘`
- `이번 달 품질 하락 구간의 원인을 패턴 분석으로 찾아줘`
- `지난 분기 코칭 효과를 데이터로 검증해줘`
