# 회의록 작성 (Meeting Notes)

핵심 결정사항과 액션 아이템이 명확한 실용적 회의록 생성 프레임워크.

## 회의록 원칙

- **결정 vs 논의 구분**: 합의된 결정과 단순 논의를 명확히 분리
- **액션 아이템 명확화**: 담당자 + 기한 + 결과물 형태 포함
- **다음 회의 연결**: 미결 사항과 다음 아젠다 명시
- **간결성**: 내용이 아닌 결론 중심 기록

## 회의 유형별 특화 포인트

**주간 팀 회의**: KPI 현황 + 주요 이슈 + 이번 주 집중 사항  
**성과 리뷰**: 목표 대비 실적 + 원인 + 조치 계획  
**코칭 면담**: 코칭 내용 + 합의 사항 + 다음 확인 일정  
**운영 기획**: 결정 사항 + 실행 계획 + 담당/기한  

## 출력 형식

ALWAYS use this exact template:

```
## 회의록

**회의명:** [회의명]  
**일시:** [날짜] [시간]  
**장소:** [장소 / 비대면]  
**참석자:** [이름1, 이름2, ...]  
**작성자:** [작성자]  
**배포:** [배포 대상]

---

### 아젠다

1. [아젠다1]
2. [아젠다2]
3. [아젠다3]

---

### 주요 논의 내용

**[아젠다1]**
- [논의 내용 요약 — 배경/현황]
- [주요 의견: 누가 무엇을 제안/지적했는가]
- [결론 또는 미결 여부]

**[아젠다2]** (동일 구조)

---

### 결정 사항 ✅

| # | 결정 내용 | 결정 근거 |
|---|-----------|-----------|
| 1 | [결정] | [근거] |
| 2 | [결정] | [근거] |

---

### 액션 아이템 📋

| # | 내용 | 담당자 | 기한 | 결과물 |
|---|------|--------|------|--------|
| 1 | [액션] | [이름] | [날짜] | [결과물 형태] |
| 2 | [액션] | [이름] | [날짜] | |
| 3 | [액션] | [이름] | [날짜] | |

---

### 미결 사항 / 보류

| 사항 | 이유 | 재논의 시점 |
|------|------|-------------|
| [사항] | [이유] | [시점] |

---

### 다음 회의

**일시:** [예정 날짜/시간]  
**주요 아젠다:** [예정 안건]  
**준비 사항:** [담당별 준비 사항]
```

## 사용 예시

- `주간 팀 회의 내용을 회의록으로 정리해줘: [내용]`
- `성과 리뷰 미팅 메모를 구조화된 회의록으로 만들어줘`
- `코칭 면담 내용을 기록용 회의록으로 작성해줘`
