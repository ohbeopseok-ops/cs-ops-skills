# 상담사 성과 벤치마킹 (Agent Benchmarking)

다차원 성과 지표를 활용한 상담사/팀 벤치마킹 프레임워크.

## 벤치마킹 차원

```
[품질 차원]
- QA 평균 점수
- 등급 분포 (S/A 비율)
- 필수 항목 준수율

[효율 차원]
- AHT (목표 대비 편차)
- FCR 달성률
- 이관률

[고객 성과 차원]
- T-NPS 예측 점수
- 불만 콜 비율
- 재연결률

[성장 차원]
- 전월 대비 점수 변화
- 코칭 반영도 (코칭 후 변화)
- 자기 개선 일관성
```

## 성과 매트릭스 (2×2)

```
         품질 높음        품질 낮음
효율 높음  [스타 ⭐]       [가속 필요 🚀]
효율 낮음  [품질 중심 📚]   [집중 지원 ⚠️]

스타: 우수 사례 공유, 멘토링 역할
가속 필요: 품질 코칭 집중
품질 중심: 효율 개선 코칭
집중 지원: 개인 개선 계획 필요
```

## 출력 형식

ALWAYS use this exact template:

```
## 상담사 성과 벤치마킹

**분석 기간:** [기간]  
**대상 인원:** [N]명

---

### 종합 순위표

| 순위 | 상담사 | 품질 | 효율 | 고객성과 | 성장 | 종합 | 구분 |
|------|--------|------|------|----------|------|------|------|
| 1 | [이름] | [점] | [점] | [점] | [점] | [점] | ⭐ |
| 2 | [이름] | | | | | | |
| ... | | | | | | | |

---

### 성과 매트릭스 배치

```
품질
  ↑
  │  [품질 중심]    [스타 ⭐]
  │  [이름A]        [이름B, 이름C]
  │
  │  [집중 지원]   [가속 필요 🚀]
  │  [이름D]       [이름E]
  └─────────────────────→ 효율
```

---

### 구분별 주요 특성 및 조치

**스타 [N]명:** [이름 목록]
- 공통 강점: [강점]
- 활용 방안: [우수 사례 공유 / 멘토링 / 인센티브]

**가속 필요 [N]명:** [이름 목록]
- 주요 이슈: [품질 취약 항목]
- 코칭 우선순위: [항목]

**품질 중심 [N]명:** [이름 목록]
- 주요 이슈: [효율 관련]
- 개선 방향: [AHT 단축 / FCR 향상]

**집중 지원 [N]명:** [이름 목록]
- 즉시 조치: [개인 개선 계획 수립]

---

### 팀 전체 분포

| 지표 | 최고 | 최저 | 평균 | 표준편차 | 목표 |
|------|------|------|------|----------|------|
| QA 점수 | | | | | |
| FCR | | | | | |
| AHT | | | | | |
| T-NPS 예측 | | | | | |

---

### 우수 사례 발굴

**[스타 상담사 이름]의 차별화 포인트:**
1. [구체적 강점 행동]
2. [구체적 강점 행동]
→ 전파 방법: [팀 공유 / 동영상 / 가이드 문서]
```

## 사용 예시

- `이번 달 팀원 20명 성과 데이터로 벤치마킹 분석을 해줘`
- `스타 상담사의 차별화 특성을 분석하고 전파 방안을 제시해줘`
- `집중 지원 대상 상담사를 식별하고 개입 우선순위를 정해줘`
