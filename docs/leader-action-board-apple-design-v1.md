## 범위
2026-10-20 맞춤제안팀 관리자용 Leader Action Board 파일럿의 시각·인터랙션 개선 기준. **기존 업무 로직, 데이터, 개인정보 정책은 변경하지 않는다.** 앱 저장소는 별도 식별 후 기능 PR에서 적용한다.

## 실제 업무 우선순위
1. 팀 선택(1팀·2팀) → 상담사 선택 → 최근 5건·누적 이력 → 오늘 코칭 필요 TOP5 → 모니터링 → 면담일지 복사의 작업 흐름을 유지한다.
2. 팀 1: 황우연 팀장·서홍규 코치; 팀 2: 정승호 팀장·오승관 코치. 2026-10-12 명부 기준 각 9명. 임의의 이름·사번·평가 데이터를 추가하지 않는다.
3. 면담일지 출력은 **상황 / 계획 / 면담내용 / 상담사다짐 / 선택적 퇴직우려 케어포인트**를 각각 수정·원클릭 일반 텍스트 복사할 수 있어야 한다. 관찰·면담 사실과 공동 합의된 행동만 사용. 상담사 다짐이나 퇴직 위험을 자동 조작·추정하지 않는다.
4. 제안기회·미시도 사유·적극시도 근거는 별도 필드로 보존하고, 코칭 및 재평가로 연결한다.

## Apple Design 원칙 적용
- **Response:** 버튼 누름·선택에 즉시 시각 피드백. 저장 성공 메시지는 실제 저장 완료 이후에만.
- **Purpose / Simplicity:** 핵심 수치, 상담사 검색, 필수 입력을 상단에. 고급 옵션은 별도 펼침.
- **Typography:** 시스템 한글 폰트, 읽기 쉬운 14–16px 본문, 표·수치의 견고한 대비. 작은 텍스트 과다 사용 금지.
- **Materials:** 헤더 정도에만 절제된 반투명 효과. 상담 데이터 본문은 불투명 배경으로 가독성 보장.
- **Spatial consistency:** 탭·시트·상세패널은 같은 위치에서 열고 같은 방향으로 닫기.
- **Motion:** 필요한 곳만 120–220ms 전환. 데이터 필터링·복사·저장은 모션보다 반응 속도 우선. 드래그/스와이프가 실제 존재할 때만 velocity-aware spring 검토.
- **Accessibility:** 키보드 초점, 화면 낭독 라벨, 44px 내외 터치 타깃, 명확한 오류, `prefers-reduced-motion`, 고대비, 모바일 확대 지원.
- **Safety / Agency:** 위험한 삭제에는 확인/되돌리기. 편집 내용 미저장 이탈 보호. 실제 데이터와 데모 데이터 구분.

## 검증 Gate
- 390/430 모바일, 1280+ PC, 키보드 탐색 및 200% 확대
- 상담사 변경 시 다른 상담사의 이력·초안 데이터가 섞이지 않을 것
- 5개 면담 필드 복사·수정·빈 값 처리 정상
- 코칭 이력 최근5건 + 누적 및 TOP5 근거 정확
- 세부 평가 로직과 저장 데이터 구조 불변
- Reduced Motion 정상, 모든 인터랙션 명시적 동작, 콘솔 오류 0건
