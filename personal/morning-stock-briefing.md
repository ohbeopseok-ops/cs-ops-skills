## 장마감 브리핑 — ChatGPT 메타프롬프트 병합 이력

2026-07-27 사용자가 제공한 ChatGPT 지침(6종목 워치리스트, 사실/해석/추론 구분,
매수매도 단정 회피, 블로그 후보 등)을 ABC(Antecedent-Behavior-Consequence) 프레임으로
분석한 뒤, 좋은 부분을 기존 장마감 루틴에 병합했다. 원 지침에서 발견된 4개 구멍과
패치 내용:

| 구멍 | 원 지침 | 패치 |
|---|---|---|
| 표기 규칙 없음 | "사실/해석/추론 구분"만 지시, 표기법 없음 | `.tag-fact` / `.tag-interp` / `.tag-infer` 3종 배지 정의, 모든 서술 문장에 필수 부착 |
| 데이터 실패 시 행동 미정의 | 없음 | "확인 불가" 표기 + 추정치를 사실처럼 쓰지 않기 규칙 명시 |
| 도구명 불일치 | "playmcp의 카카오톡 나에게 보내기" (실제 도구명 아님) | `mcp__PlayMCP__KakaotalkChat-MemoChat` 정확한 이름 명시 |
| 상세 배포 채널 없음 | 200자 카톡 요약만 | 기존과 동일하게 Artifact 페이지 + 카톡 링크 유지 |

블로그 후보 섹션은 `.blogbox`로 시각적으로 분리해 분석 톤(신중한 헷징)과
콘텐츠 아이디어 톤(클릭 유도)이 섞이지 않게 처리했다.

## 전달 방식 — 요약은 카톡, 상세는 웹페이지

카카오톡은 메시지당 200자 제한이라 상세 정보를 담을 수 없다.
그래서 상세 브리핑은 웹페이지로 발행하고, 카톡은 요약 + 링크만 보낸다.
두 페이지 모두 매번 같은 파일을 갱신 → **URL 고정**. 이전 버전은 아티팩트 버전 기록에 남는다.
페이지는 비공개이며 claude.ai 로그인 상태에서 열린다.

### 아침 브리핑 페이지 구성 (index.html)

1. 시장 — 코스피·코스닥·S&P500·나스닥 타일 + 해설
2. 보유 종목 — 종가·등락·실적 지표·확인 포인트
3. 주요 뉴스
4. 이번 주 일정 — 날짜순 타임라인
5. 오늘의 판단 + 면책 문구

### 장마감 브리핑 페이지 구성 (close.html)

1. 마감 지수 — 코스피·코스닥 + 거래량·거래대금
2. 투자주체별 매매 — 개인·외국인·기관 순매수·순매도 (양수=빨강, 음수=파랑 — 등락 색과 같은 논리 재사용)
3. 업종별 낙폭/등락 — 1위를 100%로 둔 비례 막대 (순위가 실제 정보이므로 랭킹 형태 사용)
4. 보유 종목 마감
5. 오늘 밤 확인할 것 — 미국 개장 등 야간 이벤트
6. 내일 준비할 것 + 면책 문구

두 페이지는 동일한 디자인 토큰(색·타이포·컴포넌트)을 공유해 하나의 시스템처럼 보이게 했다.
갱신할 때마다 새로 디자인하지 말고 기존 구조에 수치·문구만 갈아끼울 것.

### 디자인 규칙 (갱신 시 유지할 것)

- **한국 증시 관례**: 상승 = 빨강(`.is-up`), 하락 = 파랑(`.is-down`). 서구식 녹/적을 쓰지 않는다.
- 강조색(앰버)은 구조 요소 전용 — 등락 색과 절대 겹치지 않게 한다.
- 한글 웹폰트는 용량 때문에 인라인 불가 → 시스템 스택 사용, 숫자만 모노스페이스 + `tabular-nums`.
- 갱신 시 디자인을 새로 만들지 말고 날짜·수치·문구만 교체한다.

## 환경 제약 (영상과 다른 점)

| 영상 방식 | 이 환경 | 대체 방법 |
|---|---|---|
| pykrx로 국내 주가 조회 | KRX 로그인(KRX_ID/PW) 필요 + 데이터 미반환 | WebSearch |
| yfinance로 해외 주가 조회 | yahoo.com 차단 (프록시 403) | WebSearch |
| 카톡 나에게 보내기 | 사용 가능하나 200자 제한 | 요약 + 링크 |

## 이메일 발송을 안 쓰는 이유 (2026-07-27 조사)

| 경로 | 검증 결과 |
|---|---|
| Gmail 커넥터 | send 도구 없음 (16개 전수 확인). 초안 작성까지만 가능 |
| SMTP 587/465 | 차단 |
| Gmail REST API | 도달 가능(200). 단 OAuth refresh token을 환경변수에 상시 보관해야 함 |
| Resend / SendGrid | 차단 |

→ 메일 발송 권한을 가진 장기 자격증명을 보관하는 비용 대비 이득이 없어,
**웹페이지 + 카톡 링크** 방식을 채택. 이메일 아카이브가 필요해지면
사용자 Google 계정 안에서 도는 Apps Script로 초안을 자동 발송하는 방법이 있다
(자격증명이 이 환경에 들어오지 않음).

Claude 세션에서 말로 요청하면 `update_trigger`로 루틴 프롬프트를 갱신한다.

- 시간 변경: "브리핑 8시로 바꿔줘" → KST 기준을 UTC로 환산 (8시 KST = `0 23 * * *`)
- 중단: "아침 브리핑 꺼줘"
