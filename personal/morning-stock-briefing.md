# 아침 주식 브리핑 자동화 세팅

> 유튜브 "99% 모르는 AI로 주식수익 극대화 하는 법 (지식인사이드 EP.29)" 방식을 Claude Code 원격 세션 환경에 맞게 재현한 세팅 기록.

## 구성

- **스케줄**: 매일 오전 7:00 KST (UTC 22:00, cron `0 22 * * *`)
- **트리거**: Claude Code Routine `trig_01JTCzGgYqGaaBKR3JXhF6P4` — "아침 주식 브리핑 (매일 7시 KST)"
- **데이터 수집**: Claude 내장 WebSearch (주가·지수·뉴스·이벤트)
- **발송 채널**: PlayMCP `KakaotalkChat-MemoChat` → 카카오톡 "나와의 채팅"

## 브리핑 구성 (카톡 메시지 3~5개로 분할 발송)

1. 📊 시장 요약 — 미국 증시(S&P500·나스닥·다우) + 코스피/코스닥
2. 💼 포트폴리오 현황 — 보유 종목별 종가·등락률 (미등록 시 대형주 동향)
3. 📰 주요 뉴스
4. 💡 오늘의 투자 아이디어 + 면책 문구

## 환경 제약 (영상과 다른 점)

| 영상 방식 | 이 환경 | 대체 방법 |
|---|---|---|
| pykrx로 국내 주가 조회 | KRX 로그인(KRX_ID/PW) 필요 + 데이터 미반환 | WebSearch |
| yfinance로 해외 주가 조회 | 네트워크 정책상 yahoo.com 차단 (프록시 403) | WebSearch |
| 카톡 나에게 보내기 | 동일하게 사용 가능 | 메시지당 200자 제한 → 분할 발송 |

## 포트폴리오 변경 방법

Claude 세션에서 "포트폴리오를 ○○○, ○○○로 바꿔줘"라고 말하면
`update_trigger`로 루틴 프롬프트의 보유 종목 목록을 갱신한다.

## 시간 변경 방법

"브리핑 시간을 8시로 바꿔줘" → cron을 KST 기준으로 환산해 갱신 (예: 8시 KST = `0 23 * * *`).
