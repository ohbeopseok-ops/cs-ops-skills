# 아침 주식 브리핑 자동화 세팅

> 유튜브 "99% 모르는 AI로 주식수익 극대화 하는 법 (지식인사이드 EP.29)" 방식을 Claude Code 원격 세션 환경에 맞게 재현한 세팅 기록.

## 구성

- **스케줄**: 매일 오전 7:00 KST (UTC 22:00, cron `0 22 * * *`)
- **트리거**: Claude Code Routine `trig_01JTCzGgYqGaaBKR3JXhF6P4`
- **데이터 수집**: Claude 내장 WebSearch
- **산출물**: 상세 브리핑 웹페이지(Artifact) + 카카오톡 요약 1건 + 링크
- **보유 종목**: 삼성전자(005930)

## 전달 방식 — 요약은 카톡, 상세는 웹페이지

카카오톡은 메시지당 200자 제한이라 상세 정보를 담을 수 없다.
그래서 상세 브리핑은 웹페이지로 발행하고, 카톡은 요약 + 링크만 보낸다.

- **브리핑 페이지**: <https://claude.ai/code/artifact/7b609ba4-5b8d-4507-957c-628d13d61105>
- **소스 파일**: `personal/briefing/index.html`
- 매일 같은 파일을 갱신 → **URL 고정**. 이전 버전은 아티팩트 버전 기록에 남는다.
- 페이지는 비공개이며 claude.ai 로그인 상태에서 열린다.

### 페이지 구성

1. 시장 — 코스피·코스닥·S&P500·나스닥 타일 + 해설
2. 보유 종목 — 종가·등락·실적 지표·확인 포인트
3. 주요 뉴스
4. 이번 주 일정 — 날짜순 타임라인
5. 오늘의 판단 + 면책 문구

### 디자인 규칙 (갱신 시 유지할 것)

- **한국 증시 관례**: 상승 = 빨강(`.is-up`), 하락 = 파랑(`.is-down`). 서구식 녹/적을 쓰지 않는다.
- 강조색(앰버)은 구조 요소 전용 — 등락 색과 절대 겹치지 않게 한다.
- 한글 웹폰트는 용량 때문에 인라인 불가 → 시스템 스택 사용, 숫자만 모노스페이스 + `tabular-nums`.
- 갱신 시 디자인을 새로 만들지 말고 날짜·수치·문구만 교체한다.

## 환경 제약 (영상과 다른 점)

| 영상 방식 | 이 환경 | 대체 방법 |
|---|---|---|
| pykrx로 국내 주가 조회 | KRX 로그인(KRX_ID/PW) 필요 + 데이터 미반환 | WebSearch |
| yfinance로 해외 주가 조회 | yahoo.com 차단 (프록시 403) | WebSearch |
| 카톡 나에게 보내기 | 사용 가능하나 200자 제한 | 요약 + 링크 |

## 이메일 발송을 안 쓰는 이유 (2026-07-27 조사)

| 경로 | 검증 결과 |
|---|---|
| Gmail 커넥터 | send 도구 없음 (16개 전수 확인). 초안 작성까지만 가능 |
| SMTP 587/465 | 차단 |
| Gmail REST API | 도달 가능(200). 단 OAuth refresh token을 환경변수에 상시 보관해야 함 |
| Resend / SendGrid | 차단 |

→ 메일 발송 권한을 가진 장기 자격증명을 보관하는 비용 대비 이득이 없어,
**웹페이지 + 카톡 링크** 방식을 채택. 이메일 아카이브가 필요해지면
사용자 Google 계정 안에서 도는 Apps Script로 초안을 자동 발송하는 방법이 있다
(자격증명이 이 환경에 들어오지 않음).

## 변경 방법

Claude 세션에서 말로 요청하면 `update_trigger`로 루틴 프롬프트를 갱신한다.

- 종목 변경: "포트폴리오에 ○○○ 추가해줘"
- 시간 변경: "브리핑 8시로 바꿔줘" → KST 기준을 UTC로 환산 (8시 KST = `0 23 * * *`)
- 중단: "아침 브리핑 꺼줘"
