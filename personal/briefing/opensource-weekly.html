주간 오픈소스 블로그 리서치

2026-11-07 (토) · GitHub 리서치 기반 · 네이버 블로그 글감 기획

이번 주는 "AI 에이전트가 쓰는 전용 인프라"가 눈에 띄었습니다. 에이전트 전용 헤드리스 브라우저, 서버 없이 GitHub Actions에서만 사는 AI 비서, 금융시장 전용 파운데이션 모델부터 셀프호스팅 이메일·구직 도구까지, 실제 GitHub 저장소가 존재함을 확인한 10개를 선별했습니다. 최근 다룬 프로젝트와는 겹치지 않는 새 후보로만 구성했습니다.

최우선 추천 TOP 3

RANK 1
Lightpanda
github.com/lightpanda-io/browser
크롬 기반이 아니라 Zig 언어로 밑바닥부터 새로 만든, AI 에이전트·자동화 전용 초경량 헤드리스 브라우저. Puppeteer·Playwright가 그대로 붙는 CDP 서버를 제공합니다(약 2.9만 스타, AGPL-3.0).
왜 지금 써야 하는가 — "크롬을 통째로 띄우지 않고도 AI가 웹을 쓸 수 있다"는 자원 효율 소재가 명확하고 실측 비교가 쉽습니다.
네이버에서 먹힐 이유 — "AI 브라우저 자동화 가볍게", "크롤링 서버 자원 절약" 키워드는 실무 개발자 블로그 검색에서 꾸준한 수요가 있습니다.
RANK 2
GitClaw
github.com/SawyerHood/gitclaw
서버나 별도 인프라 없이, GitHub 이슈를 열면 그 자체로 세션이 시작되고 댓글로 대화가 이어지는 개인 AI 비서. OpenClaw를 본떠 만들었지만 "GitHub Actions 안에서만 산다"는 점이 독특합니다(MIT).
왜 지금 써야 하는가 — "서버 하나 없이 AI 비서를 운영한다"는 극단적으로 가벼운 설계가 신선한 화제성을 가집니다.
네이버에서 먹힐 이유 — "깃허브 이슈로 AI 비서 쓰기", "서버 없는 AI 자동화" 검색과 바로 맞물리는 실험적 소재입니다.
RANK 3
Kronos
github.com/shiyu-coder/Kronos
일반 언어가 아니라 "금융시장의 언어"(캔들스틱·가격 흐름)를 학습한 오픈소스 파운데이션 모델. 금융 데이터를 토큰처럼 다뤄 예측·분석에 활용합니다(약 3만 7천 스타).
왜 지금 써야 하는가 — "AI가 주가 캔들을 언어처럼 이해한다"는 설정 자체가 투자·개발 양쪽 독자의 호기심을 자극합니다.
네이버에서 먹힐 이유 — "AI 주가 예측 오픈소스", "금융 파운데이션 모델" 키워드는 투자 관심층 검색량이 꾸준합니다.
