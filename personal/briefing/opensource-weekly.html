주간 오픈소스 블로그 리서치

2026-10-31 (토) · GitHub 리서치 기반 · 네이버 블로그 글감 기획

이번 주는 "AI 에이전트가 사람 대신 화면을 조작한다"는 흐름이 두드러졌습니다. 터미널·브라우저를 직접 운전하는 에이전트 도구부터 셀프호스팅 개인 AI OS, 마크다운 노트, 대시보드 플랫폼까지 실제 GitHub 저장소가 존재함을 확인한 10개를 선별했습니다. 최근 다룬 프로젝트와는 겹치지 않는 새 후보로만 구성했습니다.

최우선 추천 TOP 3

RANK 1
CORE
github.com/RedPlanetHQ/core
할 일을 평범한 텍스트로 던지면 GitHub와 과거 기억에서 맥락을 끌어와 계획을 세우고, 승인을 받은 뒤 실제로 Claude Code 세션을 돌려 PR까지 만들어주는 셀프호스팅 "개인 AI OS". 기억은 시간이 흐르는 지식 그래프로 저장됩니다(AGPL-3.0).
왜 지금 써야 하는가 — "AI 비서에게 일을 맡기고 결과만 승인한다"는 완결된 워크플로를 보여줄 수 있는 흔치 않은 프로젝트입니다.
네이버에서 먹힐 이유 — "셀프호스팅 AI 비서", "개인 AI OS" 키워드는 아직 국내에 제대로 소개된 글이 적어 선점 효과가 큽니다.
RANK 2
tui-use
github.com/onesuper/tui-use
vim, lazygit, htop처럼 사람이 키보드 앞에 있어야 하는 터미널 프로그램을, AI 에이전트가 가상 터미널(PTY)로 직접 조작하게 해주는 CLI. "BrowserUse의 터미널 버전"을 자처합니다(MIT).
왜 지금 써야 하는가 — "AI 에이전트가 멈춰버리는 지점"을 정확히 짚어주는 문제-해결 구조라 개발자 공감을 바로 얻습니다.
네이버에서 먹힐 이유 — "코딩 에이전트 터미널 조작", "AI가 vim 쓰게 하기" 같은 구체적 실전 세팅 검색과 바로 맞물립니다.
RANK 3
Safari MCP
github.com/achiya-automation/safari-mcp
크롬·Puppeteer 없이, macOS 네이티브 사파리를 애플스크립트와 스위프트 헬퍼로 직접 조작하는 80여 개 도구를 제공하는 MCP 서버. 기존 로그인 상태를 그대로 쓸 수 있다는 점이 특징입니다(MIT).
왜 지금 써야 하는가 — 맥 사용자에게 "크롬 없이도 AI가 웹을 쓸 수 있다"는 가볍고 실용적인 대안을 제시합니다.
네이버에서 먹힐 이유 — "맥에서 AI 브라우저 자동화", "클로드 사파리 연동" 검색은 국내 맥 개발자 커뮤니티에서 수요가 꾸준합니다.
