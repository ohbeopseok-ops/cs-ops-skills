주간 오픈소스 블로그 리서치

2026-11-13 (토) · GitHub 리서치 기반 · 네이버 블로그 글감 기획

이번 주는 "AI 에이전트를 위한 보안·인프라"가 눈에 띄었습니다. 제로트러스트 VPN, AI 에이전트 전용 인증 서버, 샌드박스 코딩 에이전트 인프라부터 작은 트랜스포머 챌린지, 셀프호스팅 영양 관리 앱까지, 실제 GitHub 저장소가 존재함을 확인한 10개를 선별했습니다. 최근 다룬 프로젝트와는 겹치지 않는 새 후보로만 구성했습니다.

최우선 추천 TOP 3

RANK 1
Pangolin
github.com/fosrl/pangolin
WireGuard 기반으로 만든 오픈소스 아이덴티티 기반 원격 접속 플랫폼. Twingate·Zscaler 같은 유료 제로트러스트 VPN의 오픈소스 대안을 자처합니다(약 2만 3천 스타).
왜 지금 써야 하는가 — "회사에서 쓰던 유료 VPN을 셀프호스팅으로 바꿀 수 있다"는 명확한 비용 절감 스토리가 있습니다.
네이버에서 먹힐 이유 — "제로트러스트 VPN 오픈소스", "Twingate 대안" 키워드는 중소기업 IT 담당자 검색에서 꾸준한 수요가 있습니다.
RANK 2
emdash
github.com/generalaction/emdash
여러 AI 코딩 에이전트를 Git 워크트리별로 완전히 격리해 동시에 병렬 실행하는 오픈소스 에이전틱 개발 환경(ADE). YC W26 기업이 만들었습니다.

네이버에서 먹힐 이유 — "코딩 에이전트 병렬 실행", "Git 워크트리 AI" 검색과 바로 맞물리는 실전 세팅 콘텐츠입니다.
RANK 3
AdderBoard
github.com/anadim/AdderBoard
"10자리 숫자 덧셈을 99% 이상 정확도로 해내는 가장 작은 트랜스포머는 몇 개의 파라미터로 가능할까?"를 겨루는 오픈 챌린지. Claude Code와 Codex가 같은 프롬프트로 만든 모델을 비교하며 시작됐고, 현재 손코딩 부문은 12개, 학습 부문은 67개 파라미터까지 내려갔습니다.

네이버에서 먹힐 이유 — "트랜스포머 쉽게 이해하기", "AI 모델 파라미터란" 같은 입문 검색어와 잘 맞물립니다.
