# 고령자 상담 품질 평가 (Elderly Customer QA)

65세 이상 고령 고객 상담에 적용하는 특화 평가 기준.  
일반 QA 항목 + 고령자 보호 가산 항목으로 구성.

## 고령자 상담 특화 평가 항목

### 필수 준수 항목 (위반 시 즉시 불량 처리)

- **이해 확인 생략 금지**: 안내 후 고객 이해 여부 미확인
- **빠른 말 속도**: 고령 고객이 되묻는 상황에서 속도 미조절
- **전문용어 남발**: 설명 없이 약관/기술 용어 사용
- **동의 없는 자동화 안내**: 앱/키오스크/온라인 안내를 동의 없이 강요
- **재촉**: 고객 말이 느려도 답변 재촉

### 가산 평가 항목 (+20점 추가)

```
[고령자 보호 특화] 20점 추가
├── 말 속도·발음 배려       (5점)  — 명확한 발음, 적절한 속도
├── 이해 확인 반복          (5점)  — "이해하셨나요?" 1회 이상
├── 쉬운 언어 사용          (5점)  — 전문용어 풀어서 설명
└── 자립 지원 안내          (5점)  — 스스로 해결 가능한 방법 안내
```

**고령자 상담 총점 = 일반 QA 100점 + 고령자 특화 20점 (총 120점 → 100점 환산)**

## 고령자 리스크 패턴 탐지

상담 텍스트에서 다음 패턴을 탐지하고 리스크 수준을 표시:

| 패턴 | 리스크 | 조치 |
|------|--------|------|
| 고객이 3회 이상 동일 내용 재질문 | HIGH | 즉시 코칭 대상 |
| "그냥 처리해 주세요" 유도 | HIGH | 민원 위험 |
| 요금/계약 관련 설명 없이 처리 | HIGH | 법적 위험 |
| 가족 동의 요청 거부 | MEDIUM | 모니터링 |
| 통화 중 고객 혼란 표현 | MEDIUM | 코칭 권장 |

## 사용 예시

- `이 STT 텍스트에서 고령 고객 상담 품질을 평가해줘`
- `고령자 관련 민원 리스크 패턴을 탐지해줘`
- `이번 달 고령자 상담 취약 항목을 팀별로 분석해줘`
