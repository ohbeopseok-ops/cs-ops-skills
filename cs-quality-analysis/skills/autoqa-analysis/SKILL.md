# AutoQA 트렌드 분석 (AutoQA Analysis)

AutoQA 자동 평가 데이터를 활용한 품질 추이 분석 프레임워크.

## 분석 레이어

### Layer 1: 전체 품질 지수 (팀/센터 레벨)
- 기간별 평균 점수 추이 (주간/월간)
- 등급 분포 변화 (S~D 비율)
- 필수 항목 위반율 추이

### Layer 2: 항목별 취약 패턴
- 항목별 평균 취득점 vs 배점 비율
- 전주/전월 대비 하락 항목 식별
- 팀별 공통 취약 항목 Top 3

### Layer 3: 개인 이상 징후 탐지
- 급격한 점수 하락 (전주 대비 10점 이상)
- 연속 C/D 등급 (3콜 이상)
- 특정 항목 만점 → 0점 패턴 (일관성 이상)

### Layer 4: 콜 유형별 품질 편차
- 인바운드 vs 아웃바운드 품질 차이
- 문의 유형별 취약 패턴 (요금/장애/해지/신규)
- 피크타임 vs 오프피크 품질 차이

## 분석 입력 데이터 형식

CSV 또는 표 형식으로 다음 컬럼을 기대:
```
상담사ID, 날짜, 콜유형, 총점, 서비스태도, 업무처리, 스크립트준수, 고객만족, 등급, 필수항목위반
```

ALWAYS use this exact template:

## 사용 예시

- `이 AutoQA 데이터로 이번 주 트렌드를 분석해줘 [데이터 붙여넣기]`
- `전월 대비 품질 하락 원인을 항목별로 분석해줘`
- `C등급 이하 상담사 이상 징후를 탐지해줘`
