# T-NPS 예측 분석 (T-NPS Prediction)

상담 데이터 기반 T-NPS 사전 예측 및 리스크 탐지 프레임워크.

## T-NPS 예측 모델

### 예측 변수 (입력 데이터)

```
[품질 지표] — 가중치 40%
- QA 평균 점수
- 서비스 태도 점수 (서브 지표)
- 필수 항목 위반 여부

[처리 지표] — 가중치 35%
- FCR(First Call Resolution) 여부
- AHT(Average Handle Time) 대비 편차
- 이관/재연결 여부

[고객 반응 지표] — 가중치 25%
- 통화 중 고객 감성 (부정 발화 횟수)
- 통화 시간 대비 재질문 횟수
- 종결 시 고객 톤 (STT 기반)
```

### T-NPS 예측 공식 (가중 합산)
```
예측 T-NPS = (QA점수 × 0.4) + (처리지표점수 × 0.35) + (고객반응점수 × 0.25)

리스크 분류:
- 추천 가능성 높음: 예측 75+
- 중립:            예측 55~74
- 비추천 위험:     예측 54 이하
```

### 리스크 상담사 식별 기준
```
HIGH RISK (즉시 개입)
- 비추천 위험 3콜 이상 연속
- FCR 50% 미만 + QA 70 이하
- 고객 부정 발화 5회 이상 / 콜

MEDIUM RISK (모니터링)
- 비추천 위험 비율 20% 이상
- AHT 팀 평균 +50% 이상
- 이관 비율 15% 이상

LOW RISK (예방적 관리)
- 추세 하락 (2주 연속)
```

## 사용 예시

- `이번 주 상담 데이터로 T-NPS를 예측하고 리스크 상담사를 찾아줘`
- `월말 T-NPS 목표 달성 가능성을 현재 데이터로 분석해줘`
- `T-NPS 하락 원인 Top 3를 데이터로 진단해줘`
