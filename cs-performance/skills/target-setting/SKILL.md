# 데이터 기반 목표 설정 (Target Setting)

실적 데이터와 트렌드를 분석해 합리적 목표치를 도출하는 프레임워크.

## 목표 설정 방법론

### 방법 1: 트렌드 기반 (일반적)
```
목표 = 최근 3개월 평균 + 개선 여력 × 0.5

개선 여력 = (벤치마크 - 현재 실적)
보수적 목표: 개선 여력 × 0.3
적정 목표:   개선 여력 × 0.5
도전적 목표: 개선 여력 × 0.7
```

### 방법 2: 분위수 기반 (상담사별)
```
하위 25% 상담사 → 팀 중앙값 달성 목표
중간 상담사     → 상위 25% 수준 목표
상위 25%        → 유지 + 5% 개선 목표
```

### 방법 3: 역산 기반 (경영 목표 연계)
```
센터 T-NPS 목표 → 팀별 FCR 목표 → 상담사별 품질 목표 역산
```

## 사용 예시

- `내달 T-NPS 목표를 설정해줘. 최근 3개월 실적: 74, 76, 75`
- `팀원 20명의 개인별 QA 목표를 차등 설정해줘`
- `경영 목표 T-NPS 82점을 달성하기 위한 하위 KPI 목표를 역산해줘`
