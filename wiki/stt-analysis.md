## STT 분석 3영역

### 1. 품질 분석
STT 텍스트 → QA 항목별 자동 평가 입력 데이터

| 분석 항목 | 추출 방법 |
|-----------|-----------|
| 인사/클로징 | 시작/종료 발화 패턴 매칭 |
| 공감 표현 | 공감 키워드 사전 매칭 |
| 금지 표현 | 금지어 사전 매칭 |
| 문제 파악 | 질문 횟수, 확인 발화 패턴 |

### 2. 스크립트 준수율
필수 멘트가 통화 내에 존재하는지 체크:
```
필수 멘트 유형:
- 본인 인증 절차 멘트
- 개인정보 활용 동의 안내
- 서비스 완료 확인 멘트
- 만족도 조사 안내

준수율 = (이행 멘트 수 / 전체 필수 멘트 수) × 100
목표: [미확인 — 업데이트 필요]
```

### 3. 개인정보 탐지 & 마스킹
STT 텍스트에서 개인정보 자동 탐지 후 마스킹:

| PII 유형 | 탐지 패턴 | 마스킹 형식 |
|----------|-----------|-------------|
| 주민등록번호 | 6자리-7자리 패턴 | `[주민번호 마스킹]` |
| 전화번호 | 010-XXXX-XXXX | `[전화번호 마스킹]` |
| 계좌번호 | 은행계좌 패턴 | `[계좌번호 마스킹]` |
| 주소 | 시/도 + 상세주소 | `[주소 마스킹]` |
| 이름 | 고객 호칭 후 이름 | `[고객명 마스킹]` |

**원칙:** 분석 리포트에 PII 포함 금지. 항상 마스킹 후 저장.

## STT 품질 이슈 유형

| 이슈 | 원인 | 처리 |
|------|------|------|
| 인식 오류 (노이즈) | 배경 소음, 발음 불명확 | 해당 구간 수동 검수 |
| 화자 분리 오류 | 상담사/고객 혼용 | 문맥 기반 수동 수정 |
| 외래어/전문용어 | 인식 모델 미학습 | 사전 보완 요청 |

## 고령자 STT 분석 특이사항

고령자 통화는 일반 기준과 다르게 적용 — 상세: [elderly-customer](elderly-customer.md)

- 반복 질문 빈도 높음 → 정상 패턴, 문제로 분류 금지
- 천천히 말하기로 인한 AHT 증가 → 별도 기준 적용
- 발음 불명확 → STT 오류율 높음, 수동 검수 비율 증가
