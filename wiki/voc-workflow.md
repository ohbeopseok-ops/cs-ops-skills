## VOC 처리 3단계

```
[1단계] 분류 → [2단계] 원인 분석 → [3단계] 개선 과제 도출
```

---

## 1단계: VOC 유형 분류

### 1차 분류 (문의 목적)
| 유형 | 설명 |
|------|------|
| 서비스 장애 | 인터넷/TV/전화 불통, 속도 저하 |
| 요금 이의 | 청구 오류, 요금 과다 |
| 해지/변경 | 해지 요청, 상품 변경 |
| 설치/AS | 기사 방문, 장비 교체 |
| 일반 문의 | 상품 안내, 약정 조회 |

### 2차 분류 (고객 감성)
| 감성 | 기준 |
|------|------|
| 불만 (Negative) | 부정 발화 3회↑, 재질문 반복, 높은 톤 |
| 중립 (Neutral) | 정보 요청, 감성 중립 |
| 만족 (Positive) | 감사 표현, 칭찬 언급 |

---

## 2단계: 원인 분석

### 불만 VOC 근본 원인 진단 트리
```
고객 불만
├── 서비스 품질 → 장애 원인 분석 (네트워크/장비/외부)
├── 상담 품질 → QA 평가 → coaching-system.md
├── 프로세스 → 처리 절차 복잡성, 이관 반복
└── 커뮤니케이션 → 설명 불충분, 오안내
```

### 분석 포인트
- **반복 VOC:** 동일 고객이 2회↑ 접수 → 미해결 근본 원인 존재
- **집중 시간대:** 특정 시간대 급증 → 장애 또는 외부 이벤트 연동 점검
- **상담사 편중:** 특정 상담사 불만 VOC 집중 → 개인 코칭 필요

---

## 3단계: 개선 과제 도출

개선 과제 분류:
```
즉시 조치 (당일~3일)
 → 개별 고객 재연락, 장애 복구 확인

단기 과제 (1-4주)
 → 상담사 교육, 스크립트 수정

중기 과제 (1-3개월)
 → 프로세스 개선, 시스템 개선 요청

장기 과제 (분기~)
 → 서비스 품질 구조 개선
```

---

## 넛지 마케팅 VOC 분석

상품 변경/해지 문의 중 **넛지 마케팅 효과** 분석:
- 해지 철회율: 넛지 제안 후 해지 취소 비율
- 상향 전환율: 상품 업그레이드 전환 성공 비율
- 고객 반응 감성: 제안 수락 vs 거절 시 감성 차이

→ 넛지 분석 상세: [nudge-analysis SKILL](../cs-voc/skills/nudge-analysis/SKILL.md)
