## 주간 운영 보고서

### 섹션 구조
```
1. 핵심 지표 요약 (KPI 신호등)
   - T-NPS 예측 / 전주 대비
   - QA 평균 / 전주 대비
   - FCR / AHT

2. 이슈 & 하이라이트
   - 주요 이슈 Top 3 (원인 + 조치)
   - 우수 사례 1건

3. 상담사 현황
   - HIGH RISK 상담사 현황
   - 코칭 진행 현황

4. VOC 트렌드
   - 불만 VOC 유형 Top 3
   - 전주 대비 변화

5. 다음 주 계획
   - 우선 과제
   - 예정 코칭/교육
```

### 작성 원칙
- 숫자는 반드시 **전주 대비** 포함 (+/- 및 %)
- 이슈는 원인 없는 현상 기술 금지
- 분량: A4 1-2페이지 (경영진 가독성 우선)

## 월간 성과 보고서

### 추가 섹션 (주간 + 아래 항목)
```
6. OKR 진행률
   - KR별 현재 달성률

7. 코칭 효과 분석
   - 코칭 전후 QA 점수 변화

8. 개선 과제 현황
   - 진행 중 / 완료 / 지연 항목

9. 다음 달 중점 계획
```

## 경영진 요약 (Executive Summary)

**원칙:** 숫자 3개 + 행동 1개

```
형식:
이번 [기간] [핵심 성과/이슈] — [수치]
[원인 한 줄]
다음 [기간] [핵심 조치]
```

**예시 패턴:**
```
이번 주 T-NPS 예측 [N]점 — 전주 대비 [+/-N]점
[원인: FCR 하락 / 특정 유형 불만 VOC 급증 등]
우선 조치: [코칭 대상 N명 즉시 개입 / 프로세스 X 긴급 검토]
```
