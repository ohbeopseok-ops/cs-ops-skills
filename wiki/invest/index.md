# 투자 리서치 Wiki

> ETF 자금흐름, 종목 분석, LEGEND FUND 페르소나 기록.

## 섹션

| 경로 | 내용 |
|------|------|
| `etf-flows/` | 주간 ETF 자금흐름 분석 (`[YYYY-WW].md`) |
| `themes/` | 섹터·테마별 흐름 합성 |
| `tickers/` | 종목별 분석 누적 (`[티커].md`) |
| `legend-fund/` | LEGEND FUND 페르소나 판단 이력 |

## 인제스트 커맨드

```
/ingest → ETF 흐름 인제스트
/ingest → 종목 분석 인제스트
```
