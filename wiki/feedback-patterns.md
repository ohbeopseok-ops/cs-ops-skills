## SBI 피드백 문장 구조

```
"[통화 X분경에] [고객이 재질문을 3번 반복했을 때]
 [선생님이 속도를 낮추고 다시 설명하셨는데]
 [고객 톤이 안정되고 '감사합니다'로 마무리됐어요]"
   S(상황)          B(행동)                I(영향)
```

---

## 긍정 피드백 패턴

| 상황 | 패턴 |
|------|------|
| 어려운 고객 응대 | "고객이 감정적일 때 [행동]하셨는데, 덕분에 [결과]됐습니다" |
| 복잡한 문제 해결 | "[문제 유형]을 [몇 분] 안에 해결하셨어요. 특히 [구체적 행동]이 효과적이었습니다" |
| 스크립트 준수 | "[필수 멘트]를 자연스럽게 녹이셨습니다. 고객이 거부감 없이 [반응]했어요" |

---

## 개선 피드백 패턴

### 기본 구조
```
"[상황]에서 [현재 행동]을 하셨는데,
 고객 입장에서 [영향/느낌]이 있었어요.
 대신 [구체적 대안 행동]을 해보시면
 [기대 효과]가 있을 거예요."
```

### 취약 항목별 패턴

**경청/공감 부족:**
```
"고객이 [불만 내용] 말씀하실 때 바로 해결책으로 넘어가셨는데,
 먼저 '불편 드려서 죄송합니다' 한 마디가 고객 감정을 먼저 받아주는 효과가 있어요."
```

**빠른 말 속도:**
```
"[시간대] 통화에서 설명 속도가 좀 빨랐어요.
 고객이 재질문을 [N번] 하셨거든요.
 핵심 안내 후 '이해되셨을까요?' 확인하는 습관이 도움이 돼요."
```

**스크립트 누락:**
```
"[필수 멘트]가 이번 통화에서 빠졌어요.
 고객에게 [법적/절차적 이유]로 반드시 안내해야 하는 항목이라서요.
 통화 [시점]에 자연스럽게 넣는 연습을 해볼게요."
```

## 피드백 시 절대 하지 않는 말

| 하지 않는 말 | 대신 |
|-------------|------|
| "항상 이렇게 하시잖아요" | "이번 통화에서는~" |
| "다른 분들은 잘 하시는데" | (비교 자체 금지) |
| "왜 이걸 못 하세요?" | "어떤 부분이 어려우셨나요?" |
| "그냥 이렇게 하면 되잖아요" | "이런 방식을 시도해 보면 어떨까요?" |

## 코칭 세션 마무리 패턴

```
"오늘 이야기한 것 중에 선생님이 가장 먼저 시도해보고 싶은 게 뭔가요?"
(상담사 자신의 언어로 목표 표현하게 하기)

"[X날]에 어떻게 됐는지 같이 확인해 볼게요."
(팔로우업 약속으로 마무리)
```
