## 평가 2단계 구조

### 1단계: 필수 항목 (결격 심사)
아래 항목 위반 시 **총점 0점** (감점 아님):

| 필수 항목 | 위반 예시 |
|-----------|-----------|
| 개인정보 보호 | 주민번호·계좌번호 무단 안내 |
| 고객 응대 윤리 | 폭언·욕설에 동조 또는 반응 |
| 정보 정확성 | 허위 안내, 미확인 정보 단정 |
| 통화 완결 | 고객 동의 없이 임의 종료 |

### 2단계: 항목별 가중 점수 (100점 만점)

```
[서비스 태도] 30점
├── 인사/클로징 정확성     10점
├── 경청 및 공감 표현      10점
└── 언어 품격 및 친절도    10점

[업무 처리] 40점  ← 가장 높은 비중
├── 문제 파악 정확도       15점
├── 해결책 제시 적절성     15점
└── 처리 속도 및 완결성   10점

[스크립트 준수] 20점
├── 필수 안내 멘트 이행    10점
└── 금지 표현 미사용       10점

[고객 만족 유도] 10점
├── 추가 니즈 확인          5점
└── 종결 만족도 확인        5점
```

## 등급 기준

| 등급 | 점수 범위 | 운영 의미 |
|------|-----------|-----------|
| **S** | 95–100 | 최우수 — 벤치마킹 대상, 우수 사례 공유 |
| **A** | 85–94  | 우수 — 현 수준 유지 권장 |
| **B** | 70–84  | 양호 — 취약 항목 부분 개선 필요 |
| **C** | 55–69  | 미흡 — 코칭 필요, 주간 모니터링 |
| **D** | 54 이하 | 부적격 — 즉시 개입, [risk-thresholds](risk-thresholds.md) 참조 |

## QA → 후속 액션 연계

```
S/A → 우수 사례 아카이빙, 동료 공유
B   → 취약 항목 중심 자율 학습 자료 제공
C   → coaching-system.md 코칭 플랜 적용
D   → 즉시 코칭 + 수퍼바이저 에스컬레이션
```

→ 코칭 피드백 작성 방법: [coaching-system](coaching-system.md)  
→ T-NPS와의 상관관계: [tnps-model](tnps-model.md)

## 평가 시 주의사항

- 근거 기반: 모든 점수는 STT 텍스트의 **구체적 발화** 인용
- 동일 팀 내 평가 기준 통일 적용
- C 이하 항목은 점수와 함께 **권장 행동** 필수 기재
