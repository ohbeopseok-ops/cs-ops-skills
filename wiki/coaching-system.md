## 코칭 트리거 — 언제 코칭하는가

| 조건 | 코칭 유형 | 타임라인 |
|------|-----------|----------|
| QA D등급 (54↓) | 즉시 개입 코칭 | 당일 |
| QA C등급 (55-69) | 정기 코칭 | 1주 내 |
| T-NPS HIGH RISK | 집중 코칭 | 당일~3일 |

## 피드백 구조 — SBI 모델

```
Situation (상황): 언제, 어떤 콜에서
Behavior (행동): 상담사가 구체적으로 무엇을 했는가
Impact (영향): 그 행동이 고객/점수에 어떤 영향을 미쳤는가
```

**잘한 점 먼저, 개선점 후**: 부정 피드백만 주는 코칭은 방어적 반응 유발

---

## 개선 계획 구조

```
1. 취약 항목 식별 (QA 항목별 점수에서)
2. 근본 원인 진단
   - 지식 부족? → 교육/자료 제공
   - 스킬 부족? → 롤플레이 연습
   - 태도 문제? → 동기부여 코칭
3. SMART 목표 설정
   - 구체적 수치 목표 (예: FCR 60% → 70%)
   - 2주 단위 체크포인트
4. 팔로우업 일정
```

## 코칭 세션 운영

### 사전 준비
- 평가 결과 3건 이상 리뷰
- STT 발화 근거 준비 (추상적 피드백 금지)
- 개선 목표 초안 작성

### 세션 흐름 (30분 기준)
```
[00-05] 라포 형성, 세션 목적 안내
[05-15] 잘한 점 2가지 구체적 피드백 (SBI)
[15-25] 개선 필요 2가지 + 권장 행동 (SBI)
[25-30] 개선 목표 합의, 다음 체크포인트 설정
```

### 금지 사항
- "항상 그래" / "절대 안 해" (일반화 금지)
- 다른 상담사와 비교 (개인 성장 포커스)
- 일방적 지시 (상담사 자기 언어로 목표 표현하게)

- 코칭 전후 QA 점수 비교 (2주 후)
- T-NPS 예측 점수 변화
- 취약 항목 점수 개선 추적
