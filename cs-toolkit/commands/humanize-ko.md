# /humanize-ko — 한국어 AI체 교정

`ko-humanizer` 스킬로 글의 내용은 그대로 두고 AI가 쓴 듯한 표현 습관만 제거하는 워크플로우.
[blader/humanizer](https://github.com/blader/humanizer)(MIT)의 영어 패턴을 한국어 AI체로 재구성.

## 실행 순서

1. **티 표시** — 과장된 접속("단순히 ~가 아니라"), 클로징 반복, 억지 3단 구성, 장식용 볼드, 챗봇 잔재 등 21개 패턴 점검
2. **초안 재작성** — 사실·숫자·인용은 보존, 표현만 교체
3. **검증** — 빠지거나 추가된 사실이 있는지, 여전히 AI 같은 부분이 있는지 재확인
4. **최종본** — 문단 단위로 다시 쓰고 문장 길이를 섞음

## 사용법

```
/humanize-ko [원고 텍스트]
/humanize-ko file [파일 경로]           ← 본문만 수정, 코드/링크/프런트매터 보존
/humanize-ko voice [샘플 글] / [원고]   ← 샘플 글의 어투에 맞춰 재작성
```

## 출력

- 표시된 AI체 패턴 요약
- 최종 재작성본

## 적용 대상

JOYLAB 콘텐츠(네이버 블로그, Tistory, Threads, 투자 리포트) 발행 전 최종 교정, CS 보고서·코칭 피드백의 과장 표현 제거.
