# /wiki-lint — Wiki 정기 점검

**목적:** wiki/ 폴더 전체를 스캔해서 품질 이슈를 탐지하고 리포트를 출력한다.

**실행 스킬 체인:** (없음 — 직접 wiki/ 파일 분석)

---

## 사용법

```
/wiki-lint              ← 전체 점검
/wiki-lint --fix        ← 자동 수정 가능한 항목만 처리 (날짜 갱신 등)
/wiki-lint --summary    ← 이슈 목록만 (상세 설명 없이)
```

---

## 실행 절차

### Step 1: 파일 목록 수집
`wiki/` 폴더의 모든 `.md` 파일 목록을 수집한다.  
특수 파일 제외: `index.md`, `log.md`, `schema.md`

### Step 2: 6개 항목 점검

**🔴 HIGH — 즉시 수정 필요**

**[H1] 고아 페이지**
- `wiki/index.md`에 링크되지 않은 `.md` 파일 탐지
- 수정: index.md에 추가하거나 파일 삭제

**[H2] 끊긴 링크**
- 각 페이지의 `(*.md)` 형태 링크에서 대상 파일 존재 여부 확인
- 수정: 링크 수정 또는 대상 파일 생성

**[H3] 미해결 충돌 태그**
- 전체 페이지에서 `⚠️ 충돌` 텍스트 검색
- 수정: 사용자 확인 후 올바른 값으로 교체 + 태그 제거

**🟡 MEDIUM — 1주 내 처리**

**[M1] 미확인 태그 누적**
- 전체 페이지에서 `[미확인]` 텍스트 검색
- 수정: 실제 값 확인 후 대체 또는 `[확인불가]`로 전환

**[M2] 오래된 페이지**
- 헤더의 `최종 수정:` 날짜가 90일 초과인 페이지
- 수정: 내용 검토 후 최신화 또는 날짜 갱신

**🟢 LOW — 다음 lint 전까지**

**[L1] 고립 페이지**
- 다른 어떤 wiki 페이지에서도 링크되지 않는 페이지
- 수정: 관련 페이지에 링크 추가 또는 index.md 카테고리 확인

### Step 3: 리포트 출력

ALWAYS use this exact template:

```
## Wiki Lint 리포트

**점검 일시:** YYYY-MM-DD  
**점검 페이지 수:** N개  
**발견 이슈:** 🔴 N건 · 🟡 N건 · 🟢 N건

---

### 🔴 HIGH (즉시 수정)

**[H1] 고아 페이지** — N건
- `파일명.md` → 조치: [index.md 추가 / 삭제 검토]

**[H2] 끊긴 링크** — N건
- `파일명.md` 내 `[텍스트](대상.md)` → 대상 없음

**[H3] 미해결 충돌** — N건
- `파일명.md` → ⚠️ 충돌 내용 요약

---

### 🟡 MEDIUM (1주 내)

**[M1] 미확인 태그** — N건
- `파일명.md` → [미확인] 항목: 내용 요약

**[M2] 오래된 페이지** — N건
- `파일명.md` → 최종 수정: YYYY-MM-DD (N일 경과)

---

### 🟢 LOW

**[L1] 고립 페이지** — N건
- `파일명.md` → 참조하는 페이지 없음

---

### 권장 조치 순서

1. [가장 시급한 항목]
2. [두 번째]
3. [세 번째]

**다음 lint 권장 일정:** YYYY-MM-DD (90일 후)
```

### Step 4: log.md 기록

```
## YYYY-MM-DD

**Lint 실행**
- 점검 페이지: N개
- 발견 이슈: 🔴 N · 🟡 N · 🟢 N
- 주요 이슈: [요약]
```

---

## 이슈 없을 때

```
## Wiki Lint 리포트

**점검 일시:** YYYY-MM-DD  
**점검 페이지 수:** N개  
**발견 이슈:** 없음 ✅

모든 링크 유효 · 충돌 없음 · 미확인 태그 없음

**다음 lint 권장 일정:** YYYY-MM-DD
```
