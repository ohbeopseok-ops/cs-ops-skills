# 테스트 데이터 생성 (Data Mock)

CS 운영 도구 개발 및 테스트를 위한 현실적 가상 데이터 생성 프레임워크.

## 생성 가능한 데이터 유형

### 1. 상담사 성과 데이터 (CSV)
```
컬럼: 상담사ID, 이름, 팀, QA평균, FCR, AHT, T-NPS예측, 등급, 콜건수
```

### 2. QA 평가 데이터 (CSV)
```
컬럼: 평가ID, 상담사ID, 날짜, 콜유형, 서비스태도, 업무처리, 스크립트준수, 고객만족, 총점, 등급
```

### 3. VOC 데이터 (CSV)
```
컬럼: VOC_ID, 날짜, 유형, 긴급도, 내용요약, 원인, 처리상태
```

### 4. STT 샘플 텍스트
한국어 CS 상담 시나리오 (우수/평균/취약 케이스)

### 5. KPI 주간/월간 데이터
시계열 형태로 트렌드가 포함된 KPI 데이터

## 데이터 현실성 원칙

- 이름: 한국 성명 사용 (홍길동, 김철수 등 가상)
- 수치: 실제 CS 운영 범위 내 (QA: 60-98점, FCR: 65-90%)
- 패턴: 정규분포 + 이상치 포함
- 개인정보: 모든 데이터는 완전 가상

## 출력 형식

요청 유형에 따라 CSV 또는 구조화 텍스트로 출력:

```
[CSV 형태]
상담사ID,이름,팀,QA평균,FCR,AHT,등급
A001,홍길동,1팀,87.5,82,245,A
A002,김철수,1팀,72.0,74,312,C
...

[STT 샘플 텍스트]
상담사: "네, LG U+ 홈CS [이름]입니다. 어떻게 도와드릴까요?"
고객: "요금이 갑자기 올랐는데요..."
...
```

## 사용 예시

- `상담사 30명 성과 데이터를 CSV로 만들어줘 (팀 평균 QA 79점 수준)`
- `취약 항목이 있는 STT 샘플 텍스트 3건을 만들어줘`
- `3개월 KPI 트렌드 데이터를 만들어줘 (T-NPS 하락 시나리오)`
