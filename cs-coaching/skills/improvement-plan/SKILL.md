# 개선 계획 수립 (Improvement Plan)

데이터 기반 취약 항목 진단에서 실행 가능한 개선 로드맵까지 구조화하는 프레임워크.

## 개선 계획 유형

**개인 개선 계획 (PIP: Personal Improvement Plan)**
- 대상: C등급 이하 반복 또는 급격한 하락
- 기간: 4주 집중 계획
- 구조: 주차별 목표 + 확인 포인트

**팀 개선 계획 (TIP: Team Improvement Plan)**
- 대상: 팀 공통 취약 항목 (전원 70% 이하)
- 기간: 2-4주 그룹 교육 연계
- 구조: 공통 목표 + 개인별 편차 보정

**긴급 개입 계획 (EIP: Emergency Intervention Plan)**
- 대상: D등급 또는 필수 항목 위반
- 기간: 즉시 ~ 2주
- 구조: 일별 모니터링 + 코칭 회차 증가

## 개선 계획 출력 형식

ALWAYS use this exact template:

```
## 개선 계획서

**대상:** [이름/팀]  
**계획 유형:** [PIP / TIP / EIP]  
**계획 기간:** [시작일] ~ [종료일]  
**작성자:** [팀장 이름]  
**작성일:** [날짜]

---

### 현황 진단

**현재 수준:**
- 종합 점수: [점수] (팀 평균: [점수])
- 등급: [등급]
- 취약 항목: [항목1], [항목2], [항목3]

**근본 원인 분석 (Why-Why):**
1차 원인: [취약 항목]
2차 원인: [왜 해당 항목이 낮은가]
3차 원인: [근본 원인]

---

### 개선 목표

| 항목 | 현재 | 4주 목표 | 측정 방법 |
|------|------|----------|-----------|
| [항목1] | [점수] | [목표점] | [측정 방법] |
| [항목2] | [점수] | [목표점] | [측정 방법] |
| 종합 등급 | [등급] | [목표 등급] | QA 평가 |

---

### 주차별 실행 계획

**1주차 — 인식 (Awareness)**
- 목표: 취약 항목 자기 인식 강화
- 활동: [활동 내용]
- 확인: [확인 방법] / [확인자]

**2주차 — 연습 (Practice)**
- 목표: 대체 행동 습득
- 활동: [롤플레이 / 우수 사례 청취 / 기타]
- 확인: [확인 방법]

**3주차 — 적용 (Application)**
- 목표: 실제 상담 적용
- 활동: [모니터링 강화 + 즉시 피드백]
- 확인: 주 N회 QA 집중 평가

**4주차 — 안정화 (Stabilization)**
- 목표: [목표 등급] 달성 확인
- 활동: [정규 평가 + 결과 면담]
- 확인: 최종 평가 + 계획 종료 or 연장

---

### 지원 계획

| 지원 유형 | 내용 | 담당자 | 일정 |
|-----------|------|--------|------|
| 1:1 코칭 | 주 [N]회 | [팀장] | [요일] |
| 우수 사례 청취 | [N]건 | [본인] | [기간] |
| 롤플레이 | [N]회 | [선임] | [일정] |
| QA 모니터링 | 주 [N]건 | [품질팀] | 지속 |

---

### 계획 종료 기준

성공: [목표 등급] 달성 + [N]주 유지  
연장: 목표 미달 시 2주 추가  
에스컬레이션: D등급 지속 시 [상위 조치]
```

## 사용 예시

- `QA 65점 상담사 김영희의 4주 개인 개선 계획을 수립해줘`
- `팀 전체 스크립트 준수 항목 개선을 위한 팀 계획을 만들어줘`
- `D등급 상담사 긴급 개입 계획을 작성해줘`
