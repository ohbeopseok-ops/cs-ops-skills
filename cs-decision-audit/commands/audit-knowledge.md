# /audit-knowledge — 지식베이스 감사

**실행:** pattern-audit (모순 · 반복 실수 · 폐기 후보 · 출처 없는 주장 · 고립 노트 · 미해결 질문 점검)

**사용법:**
```
/audit-knowledge [점검 대상 노트 묶음 또는 붙여넣기]
/audit-knowledge 상담품질 도메인 전체  ← 도메인 범위 지정
```

**출력:** 6개 카테고리별 감사 리포트. 노트 개수가 아니라 판단 품질 기준으로 종합 평가.

**다음 커맨드 제안:** `/decision-note` (감사에서 드러난 미해결 질문·폐기 후보를 새 판단 노트로 갱신)
